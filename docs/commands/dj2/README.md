# Команды и правила Divine Journey 2 RU

Рабочая сборка — Divine Journey 2 2.23.4 на Minecraft 1.12.2 и Forge.

| Команда | Действие |
| --- | --- |
| `/guide` | Показать краткую памятку |
| `/world` | Показать название текущего мира |
| `/sethome <имя>` / `/home <имя>` | Сохранить точку дома / вернуться домой |
| `/home list` / `/delhome <имя>` | Посмотреть дома / удалить точку |
| `/spawn` | Вернуться на спавн основного мира |
| `/resource` | Перейти на спавн ресурсного мира |
| `/rtp` | Найти случайную точку в текущем мире. Работает в Основном, Ресурсном, Аду и Сумеречном лесу |
| `/tpa <игрок>` / `/tpaccept <игрок>` | Отправить / принять запрос на телепортацию |
| `/leaderboards ftbutilities:time_played` | Посмотреть игровое время |
| `/dj2 book_of_logic` | Прочитать условия «Книги Логики» на русском |

Можно сохранить **3 дома**. Каждый участник даёт команде **50 чанков привата
и 10 прогрузок**, максимум **100 приватов и 20 прогрузок** на всю команду.
В открытом инвентаре карта FTB находится в левом верхнем углу экрана,
под значком с цветными человечками. Подсказка кнопки — «Занятые чанки».
Подробные шаги и размеры миров есть в «Памятке игрока» в лаунчере.

Чтобы забрать вещи из своей могилы, подойдите к ней и зажмите приседание
(по умолчанию `Shift`). Этот способ доступен и на защищённом спавне.

Ресурсный мир предназначен для добычи. При его вайпе инвентарь сохраняется,
а затронутые игроки возвращаются на безопасную площадку. Вайп основного
мира сбрасывает весь прогресс на этом сервере.
