# Системные требования DJ2

Лаунчер доступен для Windows x64 и Linux x64. Ориентиры рассчитаны на игру без
шейдеров под Windows 10/11 или Ubuntu 24.04 x64.

| | Минимум | Рекомендуется |
| --- | --- | --- |
| Процессор | Core i5-4460 / Ryzen 3 1200 | Core i5-10400 / Ryzen 5 3600 |
| ОЗУ компьютера | 8 ГБ | 16 ГБ |
| Графика | Intel HD 4600 / GTX 750 | GTX 1650 / RX 570 |
| Свободное место | 10 ГБ | 20 ГБ |

Для Java по умолчанию выделяется 6 ГБ из общей ОЗУ. Перед установкой лаунчер
проверяет фактическое свободное место. Эти характеристики используются как
ориентир и показаны кнопкой **«Системные требования»** на карточке DJ2.

Данные для окна берутся из [профиля сервера](../profiles/servers.toml).
