# Системные требования сборок

На карточке каждой сборки есть кнопка **«Системные требования»**. Она открывает
отдельное окно с минимальными и рекомендуемыми характеристиками, общей памятью
компьютера, процессором, графикой, местом на SSD и примечаниями для ОС/Mac.
На маленьком экране содержимое прокручивается, кнопка закрытия остаётся доступной.
Просмотр не запускает установку, не меняет память и не обращается к API.

## Что означают текущие цифры

Это **предварительные ориентиры для мультиплеера без шейдеров**, а не замеры FPS,
официальный минимум автора сборки или гарантия работы на любом похожем компьютере.
Нижний порог DJ2 ещё не подтверждён; колонка минимума прямо говорит об этом.

Для DJ2 рекомендуемый ориентир проекта — **16 ГБ общей ОЗУ**, современный
четырёхъядерный Intel/AMD с высокой производительностью одного ядра и современная
встроенная/дискретная графика. **6 ГБ для Java** берутся из существующего
`memory_default_mb`: это часть памяти компьютера, а не добавка к 16 ГБ.
Настройка ползунка и прежние предупреждения о памяти сохраняются.

**20 ГБ на SSD** — предварительный бюджет места для установки и обновлений,
не измеренный размер дистрибутива и не дисковая квота. Карты, личные миры,
дополнительные пользовательские данные и временные файлы могут потребовать больше.
Расчёт свободного места перед настоящей установкой по manifest остаётся отдельным
механизмом; эта справка его не заменяет.

Для Mac первый кандидат на игровую проверку — **Apple M1 и новее с 16 ГБ**.
Это оценка разумного целевого оборудования, не результат запуска DJ2 на Mac.
Intel Mac, точные версии ОС, подходящие JRE/natives и настоящая игра остаются
[#36](https://github.com/omkality/omkalitycraft/issues/36).
Успех Qt/portable CI не доказывает работу Minecraft или конкретный FPS.
[Prism описывает Java 8 для Intel и Apple Silicon](https://prismlauncher.org/wiki/getting-started/installing-java/#installing-java-on-macos),
но наличие Java не доказывает совместимость всех модов и графических библиотек.

Для GTNH версия ещё не выбрана: обе колонки без вымышленных чисел, статус
«Сборка готовится». Кнопка справки доступна, установка и ползунок памяти по-прежнему
отключены. Требования проверим на конкретном runtime сборки.

## Где менять описание

В `profiles/servers.toml` у каждой записи `[[servers]]` можно добавить:

- `[servers.requirements]`: `state` (`preliminary` или `pending`), `scope`,
  `minimum_note`, `platforms`, `macos`, `note` — обычный текст;
- необязательные `[servers.requirements.minimum]` и
  `[servers.requirements.recommended]`: `cpu`, `ram_gb`, `graphics`, `storage_gb`.

Профиль без этого раздела совместим с прежним форматом: окно покажет, что
требования ещё не подготовлены. Pending-профиль не принимает численные колонки;
тексты ограничены по длине, числам нужны допустимые целочисленные значения.
RAM/SSD минимума не могут превышать соответствующую рекомендацию.
Все надписи выводятся как plain text, без HTML и исполняемых ссылок.

Требования отделены от разрешения запуска и от политики Java heap.
GUI не содержит ветвлений DJ2/GTNH и не пытается оценить видеокарту по названию.
Изменение текста/чисел профиля не должно превращаться в запрет запуска слабого ПК.

## Границы проверки интерфейса

Есть проверки совместимости старого профиля, некорректных данных, сериализации,
отсутствия вымышленных минимумов, повторного открытия одного окна, Esc/кнопки
закрытия, прокрутки маленького окна и неизменности установки/памяти.
PNG для просмотра получены настоящим Qt с отдельным фиктивным аккаунтом;
это не скрин Minecraft и не испытание указанного оборудования.
Windows-превью проходит отдельный запуск упакованного EXE.
Игровая приёмка аппаратных требований остаётся открытой.
