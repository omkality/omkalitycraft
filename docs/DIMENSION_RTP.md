# Случайная телепортация в DJ2

`/rtp` переносит в безопасную точку **того же мира**. Команда доступна
в основном мире, Аду, Сумеречном лесу и ресурсном мире. Для остальных
измерений используйте игровые порталы и предусмотренные сборкой переходы.
Действуют штатные разрешения, ожидание и кулдаун FTB.

Адаптер Core проверяет границу, приваты и площадку. Он ищет только в уже
созданных чанках. С Core 0.3.13 после дальних проб проверяются области
ближе к игроку и центру границы. Так команда может найти точку и после
вайпа, когда дальние регионы ещё пусты. Все пробы делят один лимит.
Если безопасного места нет, игрок остаётся на месте. Неудачный поиск
можно повторить после короткой задержки.

## Настройки владельца

Базовые измерения перечислены в [профиле RTP](../profiles/server-defaults/dj2/rtp.json).
Подготовка ресурсного измерения добавляет его в итоговый профиль. Python
создаёт `config/omkalitycore-rtp.properties` в новой остановленной копии.
Forge читает этот файл при запуске. [Пример env](../deploy/game/dj2-rtp.example.env)

| Переменная | По умолчанию | Назначение |
| --- | ---: | --- |
| `OMK_DJ2_RTP_MIN_DISTANCE` | 1000 | Внутренний радиус дальнего поиска |
| `OMK_DJ2_RTP_MAX_DISTANCE` | 5461 | Внешний радиус дальнего поиска |
| `OMK_DJ2_RTP_BORDER_PERCENT` | 66 | Ограничение радиуса долей границы мира |
| `OMK_DJ2_RTP_ATTEMPTS` | 64 | Лимит проб |
| `OMK_DJ2_RTP_CHUNK_LOADS` | 8 | Лимит загрузок уже созданных чанков |
| `OMK_DJ2_RTP_RETRY_SECONDS` | 5 | Задержка после неудачного поиска |
| `OMK_DJ2_RTP_PROFILE` | Встроенный профиль | Путь к JSON с разрешёнными измерениями |

Дальний радиус ограничен `min(maximum, diameter × border_percent / 200 − 2)`.
В Аду ищется место под крышей. Остальные поддерживаемые миры используют
поиск на поверхности. В профиле без адаптера остаётся штатное назначение
FTB `spawn_dimension`.

Сценарий `uv run omk lab dj2-rtp --help` использует отдельный Linux Forge.
Core 0.3.13 прошёл проверку обычным игроком в только что созданном мире.
Предыдущие регрессии сохраняются в [отчёте RTP](validation/dj2-rtp-core-0.2.7-2026-11-02.json).
