# Случайная телепортация в DJ2

При `/rtp` FTB Utilities выбирает случайную точку в основном мире. Мод
проверяет границу, целевой приват и исключает океанские биомы. Он может
создавать чанки внутри границы. Права и ожидание перед переносом остаются
в FTB.

Первые три вызова не разделены паузой. С третьей попытки отсчитываются
пять минут до следующей серии. Вызов считается попыткой при приёме команды,
даже если перенос затем отменился. Отклонённый на кулдауне вызов срок не
продлевает. Состояние хранится в данных игрока и сохраняется при переподключении.

## Настройки владельца

Core 0.3.14 использует [политику версии 2](../profiles/server-defaults/dj2/omkalitycore-rtp.properties)
из `config/omkalitycore-rtp.properties`. Штатный кулдаун FTB для игрока
выставлен в `0s` в [профиле рангов](../profiles/server-defaults/dj2/ftbutilities-ranks.txt).
Дальность, число проб поиска и измерение назначения задаёт `ftbutilities.cfg`.
Мировые границы обслуживаются независимо от команды.

`uv run omk lab dj2-rtp --native --help` показывает аргументы проверки
штатного поиска и кулдауна. Профиль версии 1 используется старым режимом
стенда для воспроизведения прежнего поиска. [История прежнего профиля](https://github.com/omkality/omkalitycraft/blob/28b6e73ad38a1c47b30cb97b8e6c0ab55d897fbb/docs/DIMENSION_RTP.md)
