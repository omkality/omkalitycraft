# Ссылки и динамические страницы книг DJ2

Кандидат относится к DJ2 2.23.4 и продолжает [первую проверку вёрстки](DJ2_BOOK_LAYOUT.md).
Он применяется после вычитанного перевода и восьмистраничного «Быстрого старта».
Планы закрепляют SHA256 входного JSON и результата. Это исходные данные для
проверяемой композиции, без автоматического включения в пользовательский выпуск.

## Ссылки

В [плане](../profiles/locale-overlays/dj2-2.23.4/book-reference-repairs.json)
32 адресные правки в 27 ресурсах Roots и Mystical World. Проверяются обычные
ссылки, категории, связи статей и якоря. Вместо выбора похожего имени каждый
переход задан явно. Если статьи нет в действующей книге, убирается открывающая
команда ссылки; подпись и сброс форматирования остаются. Флаги доступности,
рецепты и игровая прогрессия не меняются.

В статическом графе семи книг проверено 887 внутренних ссылок: отсутствующих
статей и якорей не найдено. Нативный проход по 447 доступным статьям не обнаружил
ошибок сборки и маркеров неразрешённых ссылок. Это не подтверждение каждого
внешнего URL или ручного клика по всем переходам. Для одного отсутствовавшего
файла отдельно закреплены JAR, прежний русский fallback и результат композиции;
нельзя применять к нему замену без проверки этих входов.

## Карточки модификаторов Roots

[План карточек](../profiles/locale-overlays/dj2-2.23.4/book-modifier-layout.json)
разносит характеристики и описание по двум страницам. Он охватывает 220 исходных
карточек в 23 статьях: 193 доступны при текущих флагах, 27 остаются выключенными
исходными условиями сборки. Меняется также один существующий шаблон.

Затраты, предмет, имя, описание и несовместимости по-прежнему вычисляет
`SpellModifierProcessor` установленного Roots. Тексты не подменяются сохранённым
снимком чисел. Сохраняются его входные переменные, рецепты и условия страниц;
якорь остаётся на первой половине карточки. Новые поля `omk_layout_*` управляют
только видимостью компонентов штатным `guard` Patchouli.

Это существенно для установленного Patchouli 1.0-23.6: список идентификаторов
шаблонов он получает из JAR владельца книги. Новый шаблон только в каталоге
русской локализации не регистрируется и ломает сборку книги. Проверенный вариант
сохраняет исходный идентификатор; JAR не перепаковываются, Java-код не добавляется.

## Проверки и возврат

- В настоящем клиенте все 447 доступных статей собираются без ошибок.
  Для 193 карточек выполнены 1544 точных сравнения четырёх вычисляемых полей
  в обеих половинах с исходной версией.
- Измерены реальные строки шрифта: максимальный низ описания — 62, списка
  несовместимостей — 138 при рабочем пределе 146. Переполнений карточек нет.
  Самые длинные примеры просмотрены при 1280×800 и 854×480; проверены переходы
  по ссылкам на «Инверсию» и «Вдумчивое потребление».
- Все 24 ресурса возвращены к прежним байтам, затем повторно применены.
  После каждого обновления ресурсов — 447 статей без ошибок сборки.
  Личный `options.txt` не изменился.
- Linux Docker независимо воспроизводит файлы из публичных планов. Контейнер
  работает без сети, от непривилегированного пользователя, с доступом к входам
  только для чтения, лимитами 1 CPU и 256 МиБ. Это проверка данных, отдельно
  от графического Windows-клиента и настоящего Linux Docker-сервера.

Helper в `omk.book_layout` работает только с переданными байтами: он не пишет
в каталог игрока. Публикация профиля не заменяет проверку манифеста, установщика
и полного отката игрового выпуска. Откат этих ресурсов не является откатом мира.

[Протокол проверки](validation/dj2-book-repairs-2026-11-14.json).

Остальная вёрстка остаётся в #174: длинные обычные тексты, названия статей,
другие динамические шаблоны и вступление Extreme Reactors. Измеренные фрагменты
текста ещё не означают принятую вёрстку всех книг. `ready_for_players=false`;
игровой манифест, выпуск лаунчера и VPS не переключены.
