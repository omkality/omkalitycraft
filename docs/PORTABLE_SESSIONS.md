# Переносимые сессии

Лаунчер предназначен для Windows, Linux и macOS. По решению владельца проекта
он хранит сессию в собственной папке `userdata`, без зависимости от системного keyring.

`session.json` содержит адрес сервиса, ник, UUID, игровой accessToken и clientToken.
Пароль и Drasl API token для управления аккаунтом в него не записываются.
Скин загружается через authlib-injector API с игровым токеном; право менять пароль
для этого не требуется. Изменение пароля и завершение всех сессий требуют текущий пароль.
Токен управления получается только для такого действия и остаётся в памяти.

При первом входе лаунчер создаёт сильный случайный пароль **до** запроса регистрации
и показывает его один раз. Пользователь сохраняет его и подтверждает создание аккаунта.
Это начальный пароль без отдельного короткого срока действия; обязательной немедленной
смены нет. В профиле есть «Сменить пароль»: текущий пароль, новый (минимум 12 символов),
повтор нового. После успешной смены лаунчер запоминает новую игровую сессию.

[Проверка 2 ноября](validation/launcher-account-walkthrough-2026-11-02.json): настоящие Qt
widgets и отдельный Linux Drasl 4.0.0, регистрация/повторный вход/смена; старый пароль
отклонён, новый принят для прежнего UUID. Приглашение/пароль на PNG закрыты до сохранения.
Это проверка аккаунта и UI, не приёмка Minecraft или публичного сервиса.

Файл сессии не зашифрован. Получив его копию, можно представляться игроком до истечения
или отзыва игровой сессии. Он не является паролем и не разрешает менять пароль аккаунта,
но остаётся секретом. Не отправлять `userdata` другим людям, в Git, архивы диагностики
или общую синхронизацию. Шифрование с ключом в той же папке не заявляется как защита.

`userdata`, старый `auth_token.json`, `session.json` и файлы `.env` исключаются
из манифестов и подготовки контента. CDN также отказывает в прямом скачивании
таких путей, даже если файл случайно оказался в каталоге раздачи.

Запись использует временный файл и атомарную замену. На Unix временный файл создаётся
с правами 0600, новая папка — 0700; в Windows применяются унаследованные права папки.
Обновление токена выполняется при восстановлении входа. Ошибка сети или ответ 5xx
не удаляют сессию. Отказ авторизации при обновлении очищает локальную сессию.

Срок действия задаётся на стороне Drasl. Для рабочего сервиса планируется ограниченный
срок с продлением при использовании; окончательно истёкший или отозванный токен требует
повторного входа. Тестовый стенд использует срок один час, не обещание бессрочного входа.

По решению владельца кнопок забывания входа/завершения всех сессий в интерфейсе нет.
Сервисная возможность отзыва игровых сессий сохранена и требует подтверждения паролем.
При смене пароля старые игровые сессии и токен управления также отзываются.

Пароль генерируется до сетевого запроса регистрации и показывается для сохранения.
Потеря ответа сервера не лишает игрока знания пароля: можно попробовать обычный вход
с уже выданным паролем. Автоматического восстановления по одному нику нет.

Это выбранная модель удобства и угроз, а не защита от вредоносного ПО с доступом к файлам
пользователя. Успешный вход на отдельный Forge проверен; отрицательные игровые сценарии
и поведение токенов во время длительной игры требуют отдельных проверок.
