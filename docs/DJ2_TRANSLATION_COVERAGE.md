# Полнота русского перевода DJ2

Расширенное статическое сравнение от **13 ноября 2026** для [#49](https://github.com/omkality/omkalitycraft/issues/49).
Полнота перевода и стабильность важнее номера версии. **2.23.4 остаётся кандидатом**;
этот отчёт не принимает клиент, миграцию мира или player release.

## Что сравнивалось

- Существующая установленная RU 2.21.3 из неизменяемого исторического архива владельца.
- Отдельная лабораторная копия 2.23.4 с ранее подготовленными BQ/CraftTweaker/Groovy
  локализациями, не «чистая официальная русская сборка».
- [BMProjects](https://github.com/BMProjects-Development/Divine-Journey-2-Translate/tree/1f6764559cf2118b929ad880abd03b53b6f9daa0)
  на commit `1f6764559cf2118b929ad880abd03b53b6f9daa0`. README заявляет 2.23.3;
  это не гарантия других версий. BMProjects авторы pack translation, но происхождение
  каждого русского файла внутри старых mod JAR отдельно пока не установлено.
- Закреплённые upstream 2.21.3, 2.23.3, 2.23.4; пины, агрегаты и хеши —
  в [протоколе](validation/dj2-translation-coverage-2026-11-13.json).

Сканировались mod JAR `assets/*/lang`, ResourceLoader `resources/*/lang`, Groovy
assets, настроенный FM_NewFont, custom tips и Patchouli JSON. MCMCP — тестовый
инструмент, исключён из статистики player content. Внутренние EN/RU имена файлов
нормализовались по регистру: Forge 1.12.2 применяет LegacyV2Adapter для pack_format=2,
поэтому старые `ru_RU.lang` нельзя автоматически считать отсутствовавшими.

Это статическая модель с приближённым порядком sorted JAR, без vanilla assets,
динамически созданных строк и всех текстов, зашитых в class-файлы. Она не доказывает
фактический приоритет ресурсов, загрузку языка, качество смысла или отображение.
Кириллица — диагностический признак, не процент перевода; имена модов могут
правомерно совпадать с английскими. Процент «вся сборка переведена» не вычисляется.

## Сравнение основных частей

| Часть | RU 2.21.3 | Кандидат 2.23.4 | Вывод |
| --- | --- | --- | --- |
| BetterQuesting | Все 3532 актуальных EN-ключа | Все 3532 актуальных EN-ключа | Покрытие ключей сохранено; смысл проверяется отдельно |
| CraftTweaker | 655 RU-записей, один отсутствующий актуальный ключ | 659 RU-записей, все 657 актуальных ключей | Два исторических лишних ключа не считаются новым переводом |
| ContentTweaker | 730 RU-записей | Те же 730 | В обеих копиях неверный item/tile ключ Galactic Machine Frame; требуется адресная правка |
| Custom Groovy assets DJ2 | В старой версии этого слоя нет | 30/30 актуальных ключей | Прежний draft покрывает custom pack тексты, не весь GroovyScript engine |
| Loading tips | 130 русских | 129 английских, без кириллицы | Конкретная потеря вне пяти прежних внешних locale-файлов |
| Локали восьми модов | 3025 записей внутри JAR | Отсутствуют в новых JAR | Подготовлено восстановление отдельными языковыми файлами |
| Patchouli JSON | 718 файлов | 718 файлов | 717 совпадают как JSON; одна структурная правка, обнаруженной потери RU-полей нет |

В BQ обеих копий 3534 RU-записи: два исторических ключа 9999 не входят в 3532
актуальных. 835 общих RU-значений отличаются; это не равно 835 улучшениям/ошибкам.
До смыслового ревью нельзя считать одинаковые key sets доказательством корректности.

Между pinned upstream 2.23.3 и 2.23.4 BQ изменились только описания `288.desc` и
`291.desc`: состав LightningCraft-рецептов. В текущем RU кандидате уже указаны
маналмаз/кристаллический сплав/мирион и каменный ихор вместо старых ингредиентов.
Это подтверждённая адресная адаптация текста, не проверка выполнения рецепта.
Шесть obsolete Electricium/Ichor tooltip-ключей удалены upstream; возвращать их
со старым `.lang` целиком не требуется. EN candidate bytes трёх этих namespaces
совпали с pinned официальной 2.23.4.

| Ender Utilities | 504 |
| PlusTiC | 322 |
| LightningCraft | 306 |
| Mob Grinding Utils | 71 |
| Mystical Agradditions | 64 |
| PackagedAuto | 26 |
| Всего | 3025 |

У каждой из восьми пар совпали все `.class` entries и английские language bytes.
Изменённых/пропавших классов — ноль, несовпадений параметров форматирования
в переносимых значениях — ноль. Новые JAR имеют свои hash; их не заменяли старыми.

Приватный draft содержит восемь `resources/<namespace>/lang/ru_ru.lang` и только
`customTips` внутри `config/tips.cfg`. Языковые ключи отобраны по актуальному EN;
проверены UTF-8, однозначность, форматирование и SHA256. В остальных полях tips
изменений нет, кроме допустимого CRLF/LF представления файла. Классы, scripts,
recipes, DefaultQuests и миры в draft не входят.

На 53908 EN-ключах, одинаковых в старой и новой копиях, было найдено 3025 потерь
наличия RU-записей. Применение draft **в памяти проверяющего скрипта** уменьшило
потери на этом же подмножестве до нуля. Это не утверждение, что переведены все
новые тексты, и не игровая проверка восстановленных записей.

Отдельный data-only Linux Docker verifier проверил эти 3025 записей, восемь
case-sensitive путей и 130 RU tips: readonly input, без сети/socket, 1 CPU/256 МиБ,
exit 0, OOM=false; входные хеши прежние, собственный контейнер удалён. Built-in EN
Erebus имеет одну строку без `=`: Minecraft её пропускает, строгий overlay parser
отклоняет. После сохранённого первого отказа нормализован только frozen EN-вход
проверяющего скрипта; mod JAR и production parser не менялись. Это не запуск игры.

## Подсказки, книги и сохраняющиеся пробелы

Официальные tips 2.23.3/2.23.4 побайтно одинаковы. Из 129 английских tips старой
2.21.3 128 не изменились; один теперь ссылается на Omniwand вместо Morphing Tool.
130 RU tips текущего BMProjects совпадают с установленной старой русской копией.
Draft меняет соответствующее упоминание, но разницу 130/129 и смысл каждого
совета ещё нужно сверить, а не принимать совпадение порядковых индексов за доказательство.

У Patchouli 182 byte diff; 181 исчез после разбора JSON. Единственный оставшийся
файл — `twilightforest/patchouli_books/guide/book.json`: version и три macros.
Старые книги не переносятся поверх новых. EN-путь файла не означает отсутствия
перевода: содержимое может ссылаться на I18n-ключи. Рендер книг ещё не принят.

У обоих выпусков остаются неполные локализации отдельных модов; у нового
GroovyScript engine есть 2786 EN-ключей без RU, преимущественно редактор/диагностика.
Их нельзя смешивать с 30 custom DJ2 ключами или обещать перевод «всего на свете».
Для старых некорректных UTF-8 локалей WCT/WFT ошибки сохранены отдельно; их удаление
из нового состава не считается потерей 3025 валидных переносимых записей.

Прежний аудит пяти внешних locale-файлов был полезен для их структурной проверки,
но недостаточен для полноты всей сборки: он пропускал mod JAR locales и tips.
Новая проверка расширяет его, а не превращает прежние game_tested=false в true.

## Риск и следующий этап

| Изменение | Оценка и проверка |
| --- | --- |
| EN-стабильная локаль при одинаковом коде мода | Ограниченный риск данных; проверить загрузку языка, placeholders, переносы и приоритет ресурсов |
| Изменённое квестовое описание | Возможна смысловая ошибка без crash; сверить ингредиенты/совет с актуальным рецептом и JEI |
| Tips/книги | Старый совет может быть неверен; проверить смысл и визуальную вёрстку отдельно |
| Старые scripts/config/quest DB/mod code поверх нового | Недопустимый способ переноса перевода: может откатить исправления и прогрессию |
| Native OpenAL crash | Независимый блокер #163; статический перевод его не исправляет и не устанавливает причину |

Практический вывод: **есть обоснованный путь к 2.23.4 без найденного ухудшения
старого перевода**, но пока только на уровне файлов. Следующий переводческий шаг —
установить проверенный языковой слой в новую лабораторную копию, проверить runtime
I18n, русский шрифт, loading tips, BQ/JEI/tooltips/книги и выборочные рецепты.
Источники/авторство и условия распространения восьми старых локалей фиксируются
до публикации payload. Затем обычный login/play/disconnect/rejoin/restart со звуком.

Draft не установлен и не проверен в игре. Старый архив и candidate JAR остались
неизменны; подписанные manifests/публичный payload/VPS не переключались. Новизна
2.23.4 и число совпавших строк не заменяют критерии [PACK_UPGRADES.md](PACK_UPGRADES.md).
Если обычная игра кандидата остаётся нестабильной, тот же сценарий сравнивается
со старой контрольной версией, а не компенсируется бесконечным числом патчей.
