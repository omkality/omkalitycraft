# Шрифты и ник игрока

Интерфейс использует вложенный **Rubik Bold**, основной размер 15 px; ник в полях
регистрации/входа — **Monocraft Bold 4.2.1**, пиксельный шрифт в стиле Minecraft.
Шрифты загружаются только в процесс Qt, установка в ОС не требуется. Оба доступны
по SIL OFL 1.1; лицензии, закреплённые commit/source/SHA256 находятся в
`launcher/assets/fonts/`. Monocraft — отдельный авторский шрифт, не файл из Minecraft.
Источник: [IdreesInc/Monocraft](https://github.com/IdreesInc/Monocraft/tree/04d8a6f3c0fcddf9ab0ec6c21aefcf6302392464).

Для наших Java-профилей применяется `[A-Za-z0-9_]{3,16}`: 3–16 ASCII-букв, цифр или `_`.
Пробелы, кириллица, дефис, точка, управляющие символы и эмодзи не принимаются.
Qt ограничивает ввод и длину; AccountService независимо проверяет тот же шаблон
перед выдачей пароля/сетевой регистрацией. Строки из клиента не заменяют проверку Drasl.
Занятость имени проверяет Drasl в пространстве аккаунтов проекта.

[Официальная справка Minecraft](https://help.minecraft.net/hc/en-us/articles/4408950195341)
подтверждает верхнюю границу 16 символов Java profile name; официальные
[примечания 1.20.5](https://feedback.minecraft.net/hc/en-us/articles/26136167989005-Minecraft-Java-Edition-1-20-5-Armored-Paws)
также описывают допустимое имя без пробелов и специальных знаков и пример с `_`.
Минимум 3 и точный ASCII-шаблон выше — наша совместимая политика для старых Java-клиентов
и Drasl; не выдаём неполную текущую справку Microsoft за полное описание всех исторических
исключений. Это не Bedrock gamertag и не проверка занятости имени в Mojang.

После изменения UI скрин получает новое имя файла. Общие/короткие подписи не переносятся
случайно, центры form-label и input проверяются Qt-тестом. На минимальном окне карточки
сборок прокручиваются; все ссылки сообщества остаются доступны.
