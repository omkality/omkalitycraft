# Правила DJ2

- Игроку доступны **3 дома** и **50 чанков привата**. Бюджет приватов команды
  складывается из квот участников. На карте FTB один чанк занимает 16×16
  блоков. Приваты и принудительная загрузка чанков имеют отдельные лимиты.
- Основной и ресурсный спавн защищены серверными приватами. Свои вещи можно
  вернуть из могилы, зажав приседание рядом с ней. [Спавн и могилы](SPAWN_AND_GRAVES.md)
- `/resource` ведёт в отдельный ресурсный мир. `/rtp` доступен в основном
  мире, Аду, Сумеречном лесу и ресурсном мире. [Условия телепортации](DIMENSION_RTP.md)
- `/guide` показывает краткую памятку. [Команды игрока](commands/dj2/README.md)
- Игровые аккаунты работают без OP. Для модерации и вайпов используется
  [терминал владельца](OWNER_TUI.md).

При подготовке нового сервера квоты задаются через
`OMK_DJ2_CLAIMS_PER_PLAYER` и `OMK_DJ2_HOMES_PER_PLAYER`.
