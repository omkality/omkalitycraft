# Русские подписи экрана управления

Client 0.1.6 для Forge 1.12.2 дополняет выбранный русский слой DJ2 2.23.4.
Подписи, холодный старт окончательного набора и штатное завершение приняты.
`versions.json` и `bundle-lock.json` закрепляют этот исходный этап; это ещё
не переключение пользовательского выпуска. `ready_for_players=false`.

## Небольшое дополнение существующего экрана

В EnderModpackTweaks 0.5.11 уже встроен экран управления с поиском и сортировкой.
Дополнительная замена Controlling не устанавливается. Исходный enum возвращает
буквальные `Default`, `A->Z`, `Z->A`, хотя ключи перевода существуют; кнопки
внизу имеют фиксированную ширину, и длинные русские подписи пересекаются.

Поздний клиентский обработчик заменяет только название известного режима
сортировки его существующим I18n-ключом. Порядок сортировки, поиск, назначение
клавиш и запись настроек остаются в исходном моде. Используется прежний параметр
`-Domkality.appearance.forge112=true`; нового JVM-флага, GUI или owner CLI нет.
Другие языки, неизвестный режим и отсутствующий перевод сохраняют исходную подпись.
Проверка выключенной интеграции/отсутствующих целей в JVM не заменяет отдельный
игровой запуск произвольной другой сборки.

Девять коротких значений используют прежний ресурс EnderModpackTweaks:
«Конфликты», «Без клавиши», «Все», «Вид», «Группы», «А-Я», «Я-А»,
«Свободные», «Раздел». При размере окна 854×480 они помещаются в штатные кнопки.

## Семь недостающих названий клавиш

Проверен список 282 реально зарегистрированных назначений. Для семи подписей
в исходных JAR отсутствовали значения в EN и RU: автобег, два действия
заклинателя Thaumcraft, профилировщик, модификатор микроблоков, поворот сетки
против часовой стрелки и удаление заклинания Roots. Имена модов, технические
ID и командный синтаксис не заменяются ради формального процента.

Собственный файл `resources/omkalityclient/lang/ru_ru.lang` сохраняет шесть
прежних подписей Client и добавляет семь переводов. В
[controls-review.json](../profiles/locale-overlays/dj2-2.23.4/controls-review.json)
закреплены собственные тексты, JAR/классы фактических потребителей и SHA256.
Это один ресурсный файл поверх прежнего набора; исходные сторонние JAR
не перепаковываются. По отношению к принятому слою из 681 ресурса меняется
только файл EnderModpackTweaks, добавляется собственный файл; остальные 680
ресурсов, InitialInventory, рецепты и квестовая база прежние.

## Проверки и оставшийся контроль

Два совпавших сборочных прохода из Git index дали JAR
`8175e8698e276b164c8208e7e3e4f42da29b24d8e766ee0f926968085b6dd395`.
216 JVM-условий включают 25 новых проверок подписи/locale/opt-in.
Все прежние члены JAR, кроме номера версии основного класса, побайтно прежние;
добавлены поздний загрузчик, обработчик подписи и его конфигурация.
Private ABI и test-классы в runtime не входят.

Принятый ресурсный слой — 682 файла, SHA256
`39685a9288e93a5de5c47c3cf41e1aa0969bcaf1b3755e61c16d891a467167a2`.
Компоновщик возвращает 684 файла с прежним общим скриптом и новым Client.
184 связанных проверки прошли в Windows и Linux Docker; Linux отдельно
воспроизвёл состав, девять замен, семь собственных подписей и квестовый текст.
Это проверка файлов/данных; headless JVM не доказывает Mixin-трансформацию игры.

В текущем обычном графическом клиенте со строгой политикой модов проверены
окна 854×480 и 1280×800, три режима сортировки, русский поиск/фильтры,
RU→EN→RU и полный reload окончательного ресурса. Все семь названий просмотрены,
два самых длинных помещаются в малом окне. Три строки инвентаря MCP сохранились
после просмотра и перезапуска. Холодное серверное сохранение независимо
подтвердило три стартовых предмета без повторной выдачи, все 18 страниц книги,
её автора и название. Оба клиента и сервер завершились с кодом 0, без
обнаруженного краша/OOM; свои auth/volumes/scopes очищены после экспорта.
Сервер и Drasl работали в отдельных Linux Docker volumes; это не графическая
приёмка Linux/macOS Minecraft.

Ручное создание Shift-сочетания в #191 отложено отдельным контролем. Автоматический
ввод не воспроизвёл удержание модификатора; это не доказательство дефекта игры
или перевода. Прежний Shift+O и личные HOME/NONE проверены в отдельном
[этапе DefaultOptions](CLIENT_KEY_DEFAULTS.md). При заключительном старте личная
HOME сохранилась. [Протокол и ограничения](validation/client-controls-locale-2026-11-15.json).

Дополнительная сверка диска выявила штатную обработку BASE 3.14.0: его
`ResourceLoader.fixLangFile` заменяет ` += +` на `=`. В установленном JAR
закреплены версия, SHA256 и класс; все пять отличий точно совпали с этой
обработкой. Остальные 677 ресурсов совпали побайтно. Это учитывается отдельно
от хеша исходного ZIP; исходный архив и принятые пины не переписывались ради
результата работающего мода. Первый старт контроллера использовал ранний слой
681, затем окончательный 682 был применён/reload и проверен со второго старта.

## Возврат

Сохраняются прежний Client 0.1.5 и полный языковой ZIP с их пинами. Возврат
выпускает старые байты новым подписанным поколением с актуальным минимумом
лаунчера. Общий скрипт и прежние параметры запуска этой правкой не менялись.
JAR заменяется при закрытой игре. Устаревший собственный языковой файл удаляет
существующий установщик по истории подписанного состава; соседние личные файлы
не удаляются. Отказ и повторная попытка проверены в
[сценарии возврата](CLIENT_RELEASE_SNAPSHOTS.md#проверенный-возврат-добавленного-языкового-файла).
Мир и Drasl ради изменения экранных подписей не откатываются. Общий согласованный
серверный возврат остаётся в #171; VPS/Release/player manifest не переключаются.
