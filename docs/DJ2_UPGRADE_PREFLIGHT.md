# Предварительная проверка свежего DJ2

Часть [#49](https://github.com/omkality/omkalitycraft/issues/49), 2 ноября 2026.
Кандидат — **2.23.4** с адаптацией перевода BMProjects для 2.23.3. Текущий установленный
выпуск/профиль остаётся 2.21.3. Это предварительная проверка, не принятая миграция.

## Закреплённые входы

[Профиль входов](../profiles/upgrade-inputs/dj2-2.23.4.json) содержит источники/размеры/SHA256
официальных ZIP и commit перевода. `accepted=false`; это не игровой профиль лаунчера.
Загруженные ZIP сверены с digest GitHub Release, существующие payload/миры не менялись.

[Manifest-проверка двух выпусков](validation/dj2-release-inputs-2026-11-02.json):
2.23.3 и 2.23.4 имеют одинаковые 223 записи mod project/file IDs и
Minecraft 1.12.2 / Forge 14.23.5.2860. Это не означает отсутствие изменений scripts
или совпадение с нашей 2.21.3. [Upstream](https://github.com/Divine-Journey-2/Divine-Journey-2/compare/2.23.3...2.23.4)
изменил 19 файлов, включая исправление серверной загрузки JEI и два LightningCraft-рецепта.

## Exploratory Linux-стенд

[Отчёт](validation/dj2-2.23.4-startup-preflight-2026-11-02.json): **15 условий, два
старта и полный restart**. Официальный серверный ZIP распакован в новую папку;
проверены пути/дубликаты/размеры/CRC. Java 8 закреплена digest, лимиты 6 ГиБ / 4 CPU,
heap 4 ГиБ. Сохраняются штатные JAR/config/scripts, применены только лабораторные
server.properties/eula, существующий authlib-injector и закреплённый logging runtime.

Контрольный сундук создан один раз. После restart в нём осталось 17 алмазов, тип
сохранённого `Count` — TAG_Int; подтверждено независимым чтением NBT из остановленного
снимка. Проверка использует фактический spawn-чанк: произвольный сохранённый чанк
может не быть загружен без игроков. Первые проверки стенда ошибочно ожидали TAG_Byte
и доступ к выгруженному чанку; их архивы/отчёты сохранены, потери предметов не показали.

Оба процесса завершились 0, без OOM/фатальных маркеров. Собственный volume удалён
после экспорта, временный Drasl удалён. Чужие Docker-сервисы/тома не останавливались.
В журналах остаются нефатальные сообщения модов, включая signatures/vanilla advancements;
«нет fatal» не означает «нет ошибок» и не заменяет проверку CraftTweaker/Groovy/квестов.

Прототип драйвера и сырые данные владельца:
`.local/research/dj2-upgrade/run_target_startup.py`,
`.local/dj2-target-2.23.4-018f5de30d/` (отчёт, оба bounded stdout-журнала, полный
inventory входных файлов и остановленный `export/world-after.tar`). Хеш драйвера есть
в отчёте. Это пока exploratory-драйвер, не поддерживаемая публичная команда `omk`.
Общий повторяемый CLI/планировщик миграции остаётся работой #49.

## Черновик языкового слоя

В `.local/research/dj2-upgrade/translation-overlay-v1/` подготовлены только
`ru_ru.lang`: русский файл BetterQuesting с четырьмя адресными обновлениями,
10 недостающих CraftTweaker-строк и 30 Groovy-ключей. Сверены placeholders, цветовые
коды и `<br>` новых Groovy-строк. Исходные ресурсы BMProjects закреплены commit/hash.
Не копировались `mods`, `config`, рецепты, scripts или `DefaultQuests` из старого перевода.
Черновик не установлен и не подписан как выпуск; нужно проверить терминологию/книгу/JEI
в реальном клиенте, остальные смысловые расхождения и подключение шрифтового resourcepack.

## Что этот этап не доказывает

- Core не установлен; его совместимость и защиты проверяются отдельно.
- Игрок не подключался, графический клиент и русский текст не проверялись в игре.
- Это новый мир 2.23.4, **не** перенос снимка 2.21.3 и не репетиция возврата на неё.
- Полная прогрессия, модовые машины/дюпы/приваты и все script errors не приняты.
- Структуры/реальные радиусы/предгенерация миров и нагрузка VPS не проверены.

Следующие действия — по [runbook](PACK_UPGRADES.md): закончить языковой overlay,
пересмотреть адаптеры, испытать source → target на копии лабораторного мира и полный
возврат. Подписанный выпуск/профиль переключается только после приёмки.
