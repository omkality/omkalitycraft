# Ресурсный мир DJ2

`/resource` переносит на защищённый спавн ресурсного мира. `/spawn` возвращает
в основной мир. Обе команды используют общие права, ожидание и кулдаун FTB.
`/rtp` ищет точку в текущем разрешённом измерении. [Как работает RTP](DIMENSION_RTP.md)

Ресурсный мир работает как отдельное измерение JED `-18000` со своим сидом
и границей. Основной спавн защищён в квадрате X/Z ±300, ресурсный — ±100.
FTB округляет зоны до целых чанков. Если место входа перекрыто, Core ищет
другую площадку в защищённой зоне и сохраняет мешающие блоки и могилы.
[Профиль и версия JED](../profiles/server-defaults/dj2/resource-world.json) · [Генерация ресурсов](RESOURCE_GENERATION.md)

## Подготовка владельцем

Просмотр текущей политики ничего не записывает:

```console
omk policy dj2-resource
```

Для подготовки новой конфигурации из остановленной копии:

```console
omk policy dj2-resource --source-config PATH_TO_STOPPED_COPY/config --output NEW_STAGING_BUNDLE
```

Команда создаёт новый каталог. `bundle.json` с хешами появляется после
полной записи. Подключение к контейнеру выполняется отдельно.
Идентификатор и сид задаются при создании, изменение переменных
окружения само по себе не меняет сохранение.

| Переменная | По умолчанию | Допустимые значения |
| --- | ---: | --- |
| `OMK_DJ2_RESOURCE_DIMENSION` | -18000 | -32000…-2 вне занятых ID |
| `OMK_DJ2_RESOURCE_SEED` | 0 | Целый 64-битный сид |
| `OMK_DJ2_RESOURCE_DIAMETER` | 16384 | 512…100000 с учётом спавна и RTP |
| `OMK_DJ2_RESOURCE_SPAWN_RADIUS` | 100 | 16…512 с учётом лимита защищённых чанков |
| `OMK_DJ2_RESOURCE_SEARCH_CHUNK_LOADS` | 64 | 16…64 |

При подготовке нужны JED на клиенте и сервере и возможности Core
`ftb.resource`, `ftb.spawn`, `ftb.rtp` и `ftb.territories`.
[Пример профиля](../profiles/server-defaults/dj2/resource-world.json)

## Контракт безопасного сброса

Вайп запускается из TUI по `w` с подтверждением. Старое измерение
сохраняется в холодной копии. Новое создаётся с другим сидом. Игроки,
сохранённые в ресурсном мире, возвращаются в безопасную точку.
Их инвентари и общий прогресс сохраняются. Ссылки на старое измерение
проверяются перед установкой новой копии. Если тип ссылки не поддерживается,
подготовка прерывается. [Вайп из TUI](OWNER_TUI.md#вайп-мира) · [Проверка ссылок](RESOURCE_RESET_PREFLIGHT.md)

В каталоге игрового сохранения `DIM-18000/` содержит чанки и `jed_level.dat`.
Внутренний маркер `DIM-18000/.omk-resource.properties` и внешний
`omk-resource-world.properties` связывают измерение с его сидом и владельцем.
При потере или несовпадении маркеров используйте совместную холодную копию.
[Установка и восстановление](OWNER_WORLD_CUTOVERS.md)
