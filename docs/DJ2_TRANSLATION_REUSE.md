# Перенос выбранных готовых переводов Integrated Dynamics / Tunnels

Третья порция #49 для DJ2 **2.23.4** использует готовые русские значения upstream.
Приняты **265 отсутствовавших записей**: 155 Integrated Dynamics и 110 Integrated
Tunnels, в том числе **49 записей книги Tunnels**. Это интерфейсы, подсказки,
сообщения об ошибках, достижения и часть руководства. Прежние 191 собственная
запись и все 31 файла предыдущего слоя сохранены побайтно.

Это подготовка данных. Готовность всей сборки, отображение книг и совместимость
нового mod code этим не установлены. Слой пока не установлен в игровой клиент.

## Источники и отбор

- [Integrated Dynamics, PR с обновлением RU #1483](https://github.com/CyclopsMC/IntegratedDynamics/pull/1483),
  commit `fe2f10bb460252e06807f94d6a8a44813e5dc629`.
- [Integrated Tunnels, PR с обновлением RU #327](https://github.com/CyclopsMC/IntegratedTunnels/pull/327),
  commit `c8b09bd95f585076c30a9e4a613eca735ce9fe1e`.

Оба источника — JSON-локали ветки Minecraft **1.21.1**; вклад в указанных PR —
**BazZziliuS**, проект — **Cyclops**. Это атрибуция конкретных обновлений, не
утверждение об исключительном авторстве всех строк. Исходные JAR из этих веток
не используются. Совпадение номера/имени мода не является основанием переноса.

Сравниваются точный key и полное EN-значение. Допускаются только явно выбранные
missing keys нашей 1.12.2; имеющийся RU, даже если он английский, не перезаписывается.
Для каждой выбранной записи закреплены SHA256 английского и русского **значений**.
Отдельно закреплены commit, URL, SHA256 и Git blob IDs полных EN/RU JSON и LICENSE.
Публичный [`upstream-reuse.json`](../profiles/locale-overlays/dj2-2.23.4/upstream-reuse.json)
содержит эти пины и список ключей, без полного стороннего перевода.

До преобразования JSON обнаружены повторяющиеся `_comment` и один настоящий
повтор ключа `aspect.aspecttypes.integrateddynamics.integer.range` в EN/RU.
Все неоднозначные ключи исключаются целиком и записаны в метаданные; ни «первый»,
ни «последний» вариант не выбирается. JSON-адаптация выполняется только при
подготовке данных. Production `.lang` parser по-прежнему отвергает дубликаты.

После предварительного отбора было 466 подходящих по key/EN/формату кандидатов.
В этой порции выбран 265, оставшийся 201 разобран по границам scope:

- 198 записей большой книги Integrated Dynamics — отдельное смысловое ревью.
- Два названия модов оставлены оригинальными.
- Один абзац книги Tunnels не перенесён: EN называет Fluid World Exporter в разделе
  энергии, а RU — Energy World Exporter. Нужно отдельно сверить смысл с нашей версией.

Ещё **21 запись с изменённым EN** и **9 кандидатов с несовпадающей разметкой** не
прошли предварительный отбор. Это кандидаты на ревью, не 30 доказанных ошибок.
Полный перевод указанных книг/модов не объявлен завершённым. Проверенные готовые
источники Roots/Bewitchment новых переносимых строк при этих условиях не дали;
готовый современный RU не заменяется старым или сторонним целиком.

## Применение и ограничения

`reuse_reviewed_lang_values` работает только с четырьмя `.lang` byte-входами и
двумя обязательными словарями пинов. Проверяет исходный EN, выбранный RU и актуальный
EN нашей сборки; передаёт результат прежнему `render_lang` с проверкой placeholders.
Непустой одинаковый набор пинов обязателен. Пропавший key, stale EN/RU, неверный
hash, существующая запись или английская копия вместо перевода дают отказ.
Вне approved keys значения не переносятся; новые возможности современной версии
не становятся частью 1.12.2. Помощник не читает JSON, файлы, сеть или игровые данные.

При сборке вызывающая сторона обязана сначала проверить artifact/profile hashes,
исключить неоднозначные JSON keys, передать фактический RU с учётом заменяемого
ресурса и дополнительно проверить разметку/цвета/escape-переносы. Чистый bytes helper
не устанавливает авторство, лицензию, приоритет ResourceLoader или качество перевода.
Необязательным аргументом отключить его guards нельзя. CLI/GUI/API не добавлены.

MIT notice сохранён в source profile и включён в assembled layer как
`licenses/Cyclops-locales-MIT.txt`. Для этой порции notice совпадает у обоих
источников; общий разбор происхождения остальных заимствованных локалей остаётся
в #49. Всего в текущем приватном слое **34 файла**: прежние 31, два `.lang` и notice.
Recipes/scripts/quest DB/JAR/options/JourneyMap/font pack не менялись.

## Проверка

[Протокол](validation/dj2-reviewed-locale-reuse-2026-11-13.json): red 19 новых
failures при 43 прежних passes, green **69 Windows unit/CLI**, Ruff/Black.
Linux Docker на свежем readonly named volume: **11 data checks и 62 unit**,
non-root, no network/socket, 1 CPU/256 МиБ, exit 0/OOM=false. Восемь data controls
подтвердили отказ при изменении target/source EN, RU и наличии existing key.
Независимый Linux replay совпал по bytes; две Windows-композиции также совпали.
Все 34 файла проверены по хешам и Linux-регистру, seed hashes прежние; свои scopes удалены.

Это не проверка механик машин и не графический запуск Minecraft. Остаются
смысл оставшихся страниц, runtime I18n/resource priority, шрифт/размещение текста
и обычная игра со звуком. OpenAL #163 независим. `ready_for_players=false`;
signed player manifest, release и VPS не переключены.

## Продолжение — 14 ноября 2026

Отложенные 198 записей книги Dynamics, 21 changed-EN/9 markup кандидатов и
спорный энергетический абзац разобраны в [следующей порции](DJ2_GUIDE_TRANSLATIONS.md).
Добавлены 229 записей, восемь готовых book-значений адресно уточнены. Исходный
`upstream-reuse.json` и протокол третьей порции сохранены; новый `guide-review.json`
связывает продолжение с ними хешами. По ключам покрыты обе книги, кроме намеренного
английского заголовка NBT. Два названия модов остаются оригинальными.
Это не установка в клиент или графическая приёмка.
