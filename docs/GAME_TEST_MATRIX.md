# Матрица проверок первого игрового запуска

Эта матрица покрывает оговорённые функции. Статус относится к указанной сборке/платформе,
а не ко всем версиям Minecraft. Успешный тест не означает отсутствия всех возможных багов и дюпов.
Все разрушительные сценарии выполняются только в отдельном стенде с тестовыми мирами.

| Функция | Что проверяем | Текущее подтверждение |
| --- | --- | --- |
| Регистрация | Приглашение, повторный ник/код, выданный пароль, сбой ответа | Настоящий Drasl + Qt |
| Приглашения владельца | Admin login, выдача/отзыв/одноразовость, отказ игровому токену/обычному аккаунту | Настоящий Drasl + `omk admin`; это регистрация в сообществе, per-server ACL отдельно |
| Сессия | Автовход, истечение, отзыв, смена пароля, доступ к чужому профилю | Настоящий Drasl + Qt |
| Forge-вход | Правильный UUID; отказ с чужим ником, неверным и отозванным токеном | Настоящий DJ2-вход и отдельные Forge login-пробы: все четыре сценария прошли на Windows |
| Установка | Подпись, SHA256, докачка, удаление Java/модов/конфига/шрифта/библиотеки, порча с тем же размером, отмена, обновление | HTTP-тесты; полный DJ2: восстановлены ровно 6 файлов, проверены все 6284 хеша |
| Сам лаунчер | Сборка дистрибутива, обновление, подмена/откат/истечение метаданных, нерабочий `.exe` | Qt-дистрибутивы на 3 ОС; настоящее обновление Windows |
| Standalone | Java, кеш, профили, журналы, сессия и обновления внутри папки | Проверено путями/запуском; аудит действий сторонних модов продолжается |
| Память | Разные профили, слабые ПК, ограничение сверху, сохранение, фактический `-Xmx` | Автотесты политики; настоящий DJ2 запущен с выбранными 5120 МБ |
| Русский шрифт | `FM_NewFont` активен, `forceUnicodeFont=false`, текст читается в игре | Подтверждено в options.txt запущенного клиента; визуальная проверка шрифта открыта |
| Список серверов | Только совместимый сервер; без старого списка; сохранение личных записей | NBT-тесты и файл запущенного клиента; визуальная проверка меню открыта |
| Скины | Classic/slim, 64×32/64×64, плохой PNG, большой файл, чужой профиль; внешний вид в игре | API/Qt проверены; визуальная проверка в игре открыта: захват окна завершился тайм-аутом |
| JourneyMap | Квадратная основная миникарта, отключённая сетка; не сбрасывать выбор игрока | Seed/preservation проверены unit/полным ремонтом DJ2; после теста возвращён квадрат без сетки; визуальная проверка открыта |
| Состав модов | Молчаливая очистка extras, хеши; серверный отказ по FML-списку | Локальные тесты и полный DJ2; приватный Core отклонил extra/missing/version. Настоящий DJ2 вошёл. Не доказывает честность процесса |
| Гайд в лаунчере | Общие правила + инструкции/картинки выбранного профиля | Запланирован после проверки команд и выбора модов |
| Приваты | Два обычных игрока/разные команды, ломание/установка, контейнеры, механизмы, взрывы | DJ2: два non-OP игрока, ломание до/после claim и владельцем прошло; контейнеры/машины/взрывы/союзники ещё предстоят; GTNH отдельно |
| Роли | Одинаковые игровые условия; лимиты home/warp; административные исключения | DJ2: non-OP moderator с 6 точечными правами, 3 home; отказы OP/выдаче/рангам/NBT/чужим инвентарям/массовым claims. Владение warp ещё предстоит |
| Home/warp/spawn | Создание, удаление, публичность, лимиты, задержки/кулдауны, права | Реальные таймеры home/spawn/warp/TPA/back; home movement/damage, TPA 30s и цель при завершении, одноразовый back. Cooldown home переживает reconnect, сбрасывается после restart. Измерения/смерть/конкурирующие запросы далее |
| RTP | Безопасная точка, вода/лава/пустота, приват, граница, измерения, нагрузка | FTB допустил точку над магмой; **отключён в стартовом профиле**. Таймеры/отказ при малой границе проверены; безопасная замена обязательна |
| Модерация | Ban/unban, kick, mute/unmute, запрет обхода другим ником | Non-OP kick/ban/отказ rejoin/pardon; 29 guarded-сценариев Core 0.2.2: me/tell/msg/w запрещены при муте и работают после unmute, home разрешён, chat.speak учтён. Сохранение mute после reconnect/restart ещё проверить |
| Граница мира | Отдельные измерения, переходы, телепорты/порталы, увеличение без потери данных | Предстоит |
| Ресурсный мир | Вход/выход командой, корректная генерация, запрет дома при вайпе | Предстоит |
| Вайп измерений | Allowlist, резервная копия, остановка, план, восстановление, ссылки на измерения | Предстоит только в тестовом стенде |
| Резервные копии | Согласованность мира/игроков/FTB, восстановление после аварии | Предстоит |
| Откаты построек | Автор, история, локальный откат; машины/NBT/инвентари/приваты/жидкости | Предстоит; готовое Forge-решение ещё не выбрано |
| Магазин | Отдельный каталог сервера, права выдачи, повтор/ошибка команды | Позже; оплаты вручную, без сайта и платёжной интеграции |
| Версии/переводы | Откат сборки в копии мира, quest IDs, рецепты, локализация без замены логики | Позже; текущий DJ2 не обновляем ради UI |
| GTNH | Выбранная стабильная версия, русский ресурс, loader/Java, отдельные проверки всего выше | Ещё не готов; не рекламируется как доступный |
| Linux/macOS | GUI/упаковка, затем Java/natives/OpenGL, вход и все игровые функции | GUI/упаковка проверены; игра предстоит |
| Диагностика | Ротация, crash-report, секреты, автоматическая доставка, права чтения | 211 unit/UI; прежний Java flood/DJ2 вход + 13 настоящих Drasl/HTTP/CLI сценариев с синтетическим crash-report. UI экспорта убран. [Политика](LOGGING.md), [admin CLI](ADMIN.md); намеренный краш DJ2 и мониторинг VPS отдельно |
| Эксплуатация | HTTPS, восстановление аккаунта, ключи релизов, мониторинг, логи без секретов | Публичного развёртывания пока нет |

Чистый лабораторный клиент создаётся из управляемых файлов сборки. Старые миры,
`options.txt`, `servers.dat`, OP-списки и серверные пароли из прежней установки не импортируются.
В стенде можно использовать дополнительные права для воспроизведения теста; они не являются
игровой привилегией владельца на будущем сервере.
