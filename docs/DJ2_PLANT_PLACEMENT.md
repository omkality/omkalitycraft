# Рост растений у границы привата

Кандидат DJ2 2.23.4 использует Core **0.3.2** и DJ2Fix **0.1.1**. Для одной
воспроизведённой механики роста Twilight Forest проверка прав выполняется **перед
каждой записью блока**. Запрещённое назначение остаётся нетронутым; разрешённая часть
растёт по штатным правилам. Предмет расходуется обычным способом. Новых команд,
запретов предметов, изменений рецептов или квестовых данных нет.

Это узкая защита, а не обещание безопасности всех растений и механизмов сборки.
Природный рост без игрока, другие модовые записи, machines/AE2 и полное получение
квестовых предметов остаются в #29/#49. Обычные квоты и команды FTB не меняются.

## Разделение компонентов

Общий Core предоставляет необязательный `PlayerPlacementAccess`: представление прав
одного игрока на время одной синхронной серверной операции. Проверки делегируются FTB,
включая членство в команде и явные разрешения для блоков. Кэш живёт только внутри
этого вызова. Изменение владения или отзыв разрешения учитываются в следующей операции.
Новой базы приватов нет. Без FTB или с отключёнными claims сервис не устанавливается.

Core не меняет мир и не содержит patch-классов, mixin bootstrap или зависимостей от
Twilight Forest. DJ2Fix перехватывает записи только проверенной механики. API 1
расширен совместимым дополнительным сервисом; новый Fix требует Core `[0.3.2,0.4.0)`.
В профиле обязательны `ftb.player_placement`, `fix.twilight.beans` и точная версия Fix.

Ошибка адаптера запрещает дальнейшие записи защищаемой механики и один раз пишется
в серверный журнал. Обычное размещение блока продолжает работать. Перезапуск создаёт
новый сервис. Нативные исключения самой механики не маскируются как отказ в правах.

## Почему недостаточно отменить размещение

Экспериментальный Core 0.3.1 проверял снимки `MultiPlaceEvent` и отменял операцию
целиком. Проверка блоков проходила, но отдельный тест обнаружил оставшиеся предметные
побочные эффекты после восстановления TileEntity. Независимое чтение остановленного
мира подтвердило удвоение контрольного содержимого. **Кандидат отклонён** и не является
рекомендованной версией. Общая транзакционность многоблочных действий остаётся в #105.

В принятом подходе запрещённый блок вообще не заменяется. Это позволяет сохранить
его содержимое без позднего отката. Подробные воспроизведения, Java и диагностические
моды хранятся приватно, вне публичного репозитория и runtime JAR.

## Проверки и границы доказательств

Нативные опыты выполняются на локальном Linux Docker, с закреплённым Java 8,
лимитами 4 CPU / 6 GiB и heap 4 GiB. Это новые изолированные миры, настоящая Drasl
авторизация и протокольные non-OP survival-игроки. Рендер Minecraft, естественная
карта, полное прохождение сборки и нагрузка реальных игроков этим не проверяются.

Основной опыт сравнивает все 25 600 состояний блоков защищённого участка с отдельной
копией. В дополнительных опытах форма роста детерминирована диагностическим модом;
сам предмет применяется штатным вводом игрока. Проверяются точное содержимое
TileEntity, выпавшие вещи, разрешения FTB, отрицательные координаты, другое измерение,
restart и контролируемый отказ сервиса. Эти вмешательства явно отмечены в отчётах.
Диагностический мод отсутствует в обоих серверных компонентах.

После штатной остановки отдельный читатель сверяет TAR/Anvil/NBT, версии загруженных
модов, UUID, владение и сохранность предметов. Старые отчёты и JAR не переписываются;
неудачные фикстуры и отклонённые кандидаты не считаются приёмкой защиты.

Принято **435 условий на настоящих серверах**: 136 — основной рост, 89 —
TileEntity/права/миры/restart/fault, 32 — минимальный Forge, 54 — security/claims,
74 — спавн/могилы, 50 — RTP. Отдельно **124 независимые проверки** сохранений.
Контроль без нового Fix подтверждает исходный обход; отклонённый rollback и два
неполных ранних fixture-запуска не входят в эти числа. Свои 14 scopes очищены;
Windows unit/UI 1059 passed / 11 skipped, Ruff/Black, повторные SHA совпали.

Команды подготовки/повторения и полные fixtures находятся в соседнем приватном
проекте `omkalitycore/lab/`: `trees_lab.py`, `placement_edges.py`,
`verify_placement.py`, `prewrite_regressions.py`. Локальные результаты —
`omkalitycraft/.local/tree-placement-*/` и `.local/placement-edges-*/`:
`report.json`, `observations.json`, `driver.py`, `independent-validation.json`,
`export/world-after.tar`; у двух стартов также `pre-restart/world.tar`.
Файлы аккаунтов в этих папках приватные и не предназначены для публикации.

Сводные результаты и SHA256: [обезличенный протокол](validation/dj2-plant-placement-2026-11-06.json).
Живые миры, клиентский адаптер и player releases не переключаются. Для следующего
локального этапа VPS пока не нужен. Второго планировщика резервных копий не добавлено.
