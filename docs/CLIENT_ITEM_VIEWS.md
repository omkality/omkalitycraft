# Русское отображение особых предметов и книг

Client 0.1.5 для Forge 1.12.2 показывает перевод закреплённых подписей и книг
DJ2 2.23.4. Исходные ItemStack, NBT, сетевые данные, крафты и база квестов
не переписываются: сравнения предметов продолжают видеть канонический оригинал.
Это продолжение [языкового комплекта](DJ2_LANGUAGE_BUNDLE.md), не новый установщик.

## Включение и границы

По умолчанию интеграция выключена. Проверенный профиль требует двух параметров:

```
-Domkality.itemviews.locale.forge112=true
-Domkality.itemviews.profile=dj2-2.23.4
```

Они добавлены к прежним трём параметрам книг/оформления/DefaultOptions в
`profiles/locale-overlays/dj2-2.23.4/bundle-lock.json`. Компоновщик принимает
только полный согласованный набор; неполный профиль, другой выпуск и
произвольные дополнительные аргументы отклоняются. Прежние наборы из двух
и трёх параметров остаются допустимы для возврата сохранённых поколений.

Общий Java-адаптер использует собственный профиль `dj2-2.23.4.properties`:
26 правил подписей и три варианта подписанных книг. Для буквальных значений
сверяются ID/metadata и SHA256 текста. Для книги — также автор, название и
все исходные страницы; при изменении источника остаётся оригинал. Перевод
числовых lore-строк сохраняет исходное число. Пользовательские переименования
не заменяются названием сборки. Книги другого автора и неизвестные варианты
не переводятся. Это не общий перевод всех произвольных книг игроков.

Перевод работает только при русском языке. Tooltip и подпись выбранного
предмета меняются в точках отображения; глобальный `getDisplayName` прежний.
Подписанная книга получает отдельный список страниц только внутри GUI.
Записываемые книги и производные неизвестные GUI не обрабатываются. Текст
переносит штатный FontRenderer: 116 пикселей, до 12 строк на страницу; короткое
условие не разрывается между страницами. Ссылки/исполняемые события не создаются.

Профиль ограничен 64 КиБ, числа/страницы/правила имеют лимиты. Ошибка загрузки
профиля оставляет оригинал и единственное сообщение с типом ошибки, без содержимого
предметов. Компиляционные ABI-объявления и тестовые классы в runtime JAR не входят.

## Языковые данные

Собственные 13 исправлений `dj2.book_of_logic.desc0..12` находятся в
[item-view-review.json](../profiles/locale-overlays/dj2-2.23.4/item-view-review.json).
Они применены существующим `omk.localization.locale_overlay.render_lang` с пинами исходного
файла, прежнего перевода и отдельных значений. Все девять условий задачи и
числа сохранены; исправлен лишний буквальный `r` вместо кода цвета.
GUI повторно использует эти языковые ключи. Команда `/dj2 book_of_logic`
показывает тот же текст. Остальные 680 ресурсов не меняются, InitialInventory
остаётся общим прежним скриптом со стартовой книгой на 18 страницах.

## Проверки

191 JVM-условие включает распознавание источника, чужого автора, изменённой
страницы, ограничения, дубли профиля, числа, JSON-экранирование и переносы.
Частная проверка настоящего корпуса сверила 53 подписи, три варианта книг
и 171 условие сохранения/отказа. Это проверка данных, не прохождение задания.

Обычный графический клиент с MCP и без собственного диагностического мода
подключался к изолированному Linux Docker-серверу DJ2. Проверены обычный крафт
«Книги Логики», повторный вход, все восемь русских экранных страниц, tooltip,
подпись выбранного предмета, RU → EN → RU и полная перезагрузка ресурсов.
Именованные синтетические предметы проверяют отдельные варианты lore/книг,
чужого автора и пользовательское переименование; они не доказывают прохождение
головоломки. Все девять исходных строк инвентаря совпали после просмотра.

После штатной остановки независимо прочитан холодный playerdata Docker-мира:
восемь страниц настоящего крафта, варианты 1/7/7/7 страниц, авторы, названия,
пользовательское имя и числовые теги совпали с источником. Клиент/сервер exit0,
без обнаруженного краша/OOM; свои volumes/auth/scopes удалены после экспорта.
[Обезличенные результаты](validation/client-item-views-2026-11-15.json).

В публикуемом исходном профиле девять значимых конечных пробелов записаны как
`\u0020`. Все классы и остальные ресурсы побайтно совпадают с игровым JAR;
все 206 значений профиля отдельно сравнены через Java Properties и совпали.
Для этого эквивалентного кодирования новый игровой стенд не запускался.

## Возврат

Для этого клиентского слоя сохраняются прежние Client 0.1.4 и полный языковой
архив с их пинами. Возврат выпускается новым подписанным поколением по
[общему порядку](DJ2_LANGUAGE_BUNDLE.md#порядок-безопасного-возврата): прежние
байты и прежний набор из трёх параметров, без двух itemviews-параметров.
Нельзя подменять JAR или общий скрипт работающего процесса. Нельзя смешивать
новый список файлов со старым хешем архива. Личные настройки не сбрасываются.

Сам слой не требует отката мира или прогресса: он не записывает переведённый
NBT. Это не общий атомарный откат мира/БД/серверных исправлений (#171).
Player manifest, GitHub Release и VPS этим этапом не переключаются;
`ready_for_players=false` сохраняется до общей приёмки.
