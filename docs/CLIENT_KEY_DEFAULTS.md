# Сохранение начальных клавиш

OmkalityClient 0.1.4 исправляет повторный запуск DJ2 2.23.4 с DefaultOptions 9.2.8.
До исправления первый старт был правильным, но выход без открытия настроек оставлял
неполный options.txt и уже полный knownkeys.txt. При следующем запуске мод считал
клавиши настроенными, и исходные K других модов конфликтовали с квестами (#191).

## Граница изменения

Поздний клиентский адаптер включается только параметром
`-Domkality.defaults.persist.forge112=true`. Без него и на сервере интеграция выключена.
Точка изменения — ровно два List.add в reloadDefaultMappings(): чтение прежних
knownkeys и запись новых. В список попадают только клавиши, реально записанные
в options.txt. Отсутствующий файл означает пустой список; нечитаемый файл сохраняет
исходное поведение мода и даёт одно предупреждение без содержимого и путей.

Снимок читается как UTF-8, не более 8 МиБ/4096 ключей; принимаются числовые
назначения и штатные NONE/SHIFT/CONTROL/ALT. Симлинк и нестандартный файл отвергаются.
Адаптер сам не пишет options.txt, не вызывает ранний saveSettings, не переносит
клавиши лаунчера в новый механизм и не меняет способы активации модов.
Личные назначения и отключение клавиши сохраняются штатным меню игры.

Проверенный внешний артефакт DefaultOptions 9.2.8:
`1a4007ec8c503fe75faf7429b66c0ffe1555fa7a7d43147386049913ce6ebf4a`;
класс DefaultOptions:
`1cc2850cf0700af76213477c3456b835ce12f30790b2579c9d273e3bd8e5984e`.
Другие версии требуют самостоятельной приёмки. Отсутствие точек при включённой
интеграции не скрывается. Сторонний класс и его декомпиляция в Git не включены.

## Проверка

Обычный клиент с 258 модами без диагностического мода, настоящий prepare_client_defaults
и один изолированный Linux Docker-сервер с Drasl: три старта одного мира/аккаунта.
После первого выхода без Options K осталась только у Better Questing, Roots сохранил
SHIFT+O; Quark lockBuilding и CraftingTweaks compressStack остались отключёнными.
На втором старте назначили Roots HOME и отключили очки с сенсорами через меню.
Третий старт сохранил HOME/NONE. Обычное нажатие K через окно открыло GuiHomeOverride.

Новая комбинация Shift+Home через автоматизированный ввод отобразилась как HOME:
проверка редактирования новых комбинаций не принята и не выдаётся за исправленную.
Исходная SHIFT+O проверена после повторного старта. Это не полное прохождение сборки.
Все три клиента завершились штатно; сервер exit0/noOOM. Собственные доступы/тома
удалены после сохранения диагностики. [Машинный протокол](validation/client-key-defaults-2026-11-15.json).

### Дополнительная попытка через Windows — 17 ноября 2026

На свежем signed-комплекте с Client 0.1.7 первый запуск завершился с exit0 без
посещения Options. Во втором запуске тот же профиль открыл меню управления;
перед изменением сохранён контрольный снимок 282 назначений. Windows SendInput
через Computer Use отправил `Shift_L+Home` для Roots «Открыть сумку», но экран,
runtime-census и options.txt показали только HOME. Остальные 281 записи прежние,
включая библиотеку Roots SHIFT+O, K квестов и отключённые клавиши.

Это автоматизированная отправка сочетания, а не удержание физической клавиши
человеком. Прямая отправка MCP keyTyped ранее дала такой же результат. Корпус
переводов и обработчик клавиш ради этого не менялись. Удержание через MCP raw
в главном меню отказало до изменения состояния: инструмент требует загруженный мир.

До повторного запуска клиент аварийно завершился с `0xC0000005`. Windows
Application Error 1000 указал `OpenAL64.dll`, offset `0x20ddd`, как в #163.
Мир и dedicated Forge-сервер в этой попытке не запускались; saves пуст.
JRE/LWJGL/OpenAL остались штатными, звук не отключался. Fault module описывает
место падения, первопричина остаётся неизвестной. hs_err не создан; launcher
сохранил локальный incident, Crash Assistant появился и был закрыт при уборке.

Создание нового Shift-сочетания и его сохранение после перезапуска здесь
**не приняты**; ручной контроль #191 и расследование #163 остаются открытыми.
Использован pinned диагностический MCP overlay, поэтому эта попытка также не
заменяет обычные клиентские контроли выше. Приватные журналы/кадры сохранены
через 7-Zip с проверкой каждого файла; временные Drasl/доступы убраны. Автоматическая
проверка отклонила удаление своей копии клиента, тестовой session-папки и распакованного
экспорта (`blocked by policy`); они оставлены локально, повторного удаления не было.
[Протокол с пределами результата](validation/client-native-chord-2026-11-17.json).

## Возврат

Закрыть клиент, вернуть сохранённый подписанный комплект с Client 0.1.3 и прежними
параметрами. Не удалять options.txt, knownkeys.txt или начальные метки лаунчера.
Миры, рецепты, база квестов и серверный NBT этой правкой не изменяются.
При удалении только нового параметра возвращается исходное поведение DefaultOptions,
включая старый дефект на ещё не сохранённых клавишах. Полный согласованный возврат
комплектов выполняется по [общему порядку](DJ2_LANGUAGE_BUNDLE.md).
Профиль игроков, Release и VPS этой приёмкой не переключаются.
