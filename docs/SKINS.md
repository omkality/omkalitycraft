# Один скин для аккаунта

В лаунчере одна кнопка загрузки PNG. Выбирать Minecraft 1.7/1.8 или загружать отдельные
версии пользователю не нужно. Принимаются 64×64 и старые 64×32, до 256 КиБ;
анимированные, повреждённые и полностью прозрачные изображения отклоняются.
Перед отправкой PNG заново кодируется без произвольных метаданных.

Classic/Slim — модель, а не размер файла: оба варианта могут быть 64×64.
Автоматическая подсказка использует прозрачные неиспользуемые участки UV-развёртки.
Она не доказывает модель произвольного PNG: например, непрозрачный Slim неоднозначен.
Поэтому перед загрузкой есть вращающийся предпросмотр и скрытая по умолчанию настройка
«Стандартная / Узкая». Для 64×32 разрешена только стандартная модель.
Отмена предпросмотра не обращается к API. Пока операция выполняется, повторный запрос
из окна не отправляется. Скин меняется игровым токеном, management token не нужен.

Стандартный облик предоставлен владельцем 1 ноября 2026. Все три исходных варианта
сохранены без изменения пикселей; хеши и исходные имена —
`launcher/assets/skins/provenance.json`. Для текущего лаунчера выбран `default-slim.png`.
Он же подключён к Drasl как единственный штатный default skin, без принудительной
загрузки в каждый новый аккаунт и без замены уже выбранных пользовательских скинов.
Это использует [штатный механизм Drasl](https://github.com/unmojang/drasl/blob/master/doc/usage.md#default-skins).

Qt + настоящий Drasl подтвердили default/Slim metadata и загрузку/чтение пикселей
всех трёх файлов. Графический прогон Minecraft отмечается отдельно в матрице:
API/предпросмотр не доказывают внешний вид в игре. GTNH ещё не выбран/не испытан;
поддержку современных моделей в клиенте 1.7.10 нужно проверить на его конкретном составе
модов. Второй файл от игрока для этого не планируется.
