# Игровые книги и длинные описания DJ2 2.23.4

Продолжение [#49](https://github.com/omkality/omkalitycraft/issues/49).
Подготовлены исходные данные следующей редакции перевода:

- `long-text-review.json`: 171 решение, из них 170 русских значений и одно
  намеренное сохранение невербальной вокализации.
- `books/*.json`: 1998 решений по полям книг десяти модов, из них 1902 русских
  значения и 96 намеренно сохранённых литералов.

Это проверенные данные для сборки слоя. Автоматического установщика, изменения
manifest или player release здесь нет. `game_tested=false`,
`ready_for_players=false` сохраняются. Полные заимствованные локали, исходные
снимки JAR, миры и диагностические моды не публикуются.

## Что вычитано

Закончена вычитка 1608 полей из замороженного списка недостающих книг: 1189 групп
одинаковых EN/RU внутри одной книги. Разные поля сохраняют собственные адреса
и пины. Затем целиком перечитаны 356 ранее правленных полей, включая те, где
сначала менялись только заголовки модификаторов или подписи ссылок.

Исправлены инструкции, названия, условия применения, стыки предложений между
страницами и остатки машинного текста. Например, восстановление здоровья больше
не описывается как его расход; указатель на точку возрождения — как направление
к текущему месту; «голодные ножки» и «хвостовики» заменены понятными единицами
сытости. Имена предметов сверяются с установленной русской локалью. Команды,
рудный словарь, координатные параметры, значения рецептов и условия открытия
страниц сохраняются.

Ни наличие кириллицы, ни успешная проверка данных не доказывают качество
каждой фразы или её размещение в игре. Это результат вычитки конкретного
каталога, а не обещание отсутствия любого английского текста во всех модах.
Developer/API wiki исключена по решению владельца.

## Служебные поля и реальные потребители

В установленном Patchouli 1.0-23.6 `ComponentText.text` имеет `@VariableHolder`.
`VariableAssigner.resolveStringVar` воспринимает начальный `#` как поиск поля;
при неизвестном имени может вернуть пустую строку. Поэтому `#text`, `#name`,
`#cost` и остальные такие значения не переводятся. В кандидате и существующих
fallback-ресурсах проверены все 80 ссылок каталога. Намеренное переименование
поля отвергается отрицательным контролем. Только из-за сохранения литерала
не создаётся лишняя русская копия файла, если она не требуется другим текстам.

В Extra Utilities 2 1.9.9 `BookHandler.newStack` добавляет `page.text` буквально
и делит результат через FontRenderer на NBT-страницы по 13 строк. Процент в
описании глушителя — текст, а не аргумент Java Formatter. Исправлены две
опечатки самого руководства по установленным потребителям: команда называется
`xu_powersharing`; подсказка солнечной панели указывает дневное время.
Это статическая проверка кода установленного JAR, не новый нативный тест панелей.

Описание статуй Bewitchment уточняет алтарь вместо повторного «вокруг статуй»:
`TileEntityWitchesAltar` распознаёт демонические статуи и учитывает их при
увеличении запаса энергии. Условия благосклонности демонов отдельно не проверялись.
Авторские шифры сохранены. Условия и заслуги исходных переводчиков остаются
в документации и лицензионных материалах; редактирование не отменяет их вклад.

## Контракт исходных данных

Каждый книжный профиль закрепляет версию и commit DJ2, SHA256 базового
`owned-ru.json`, полный путь исходного JSON, его hash и имя/hash исходного JAR.
У каждого поля есть JSON pointer и SHA256 точного EN-значения в UTF-8.
Если по тому же адресу уже был RU-текст, закреплён и его `expected_previous_sha256`.

`reviewed_translation` содержит `ru`. `preserve_source_literal` не содержит
скопированного исходного абзаца и означает сохранение служебного значения;
его контекст указан отдельно. Прежние готовые русские тексты и явно проверенный
перенос терминов не объявлены новыми собственными переводами этих профилей.

Профили не являются разрешением извлекать JSON поверх установленной сборки.
Перед подготовкой ресурса проверяются исходник, предыдущее значение и контракт
потребителя. Затем обязательны независимая сверка собранного дерева, сохранность
нетекстовых JSON-полей, форматирования и ссылок. Неизвестный источник требует
нового ревью. Прежние owned/reuse/guide/player-text profiles не заменены.

## Проверено

В Linux Docker пройдены 20 проверок данных, 14 отрицательных контролей и
76 unit tests. Все 2169 публичных решений этой порции сопоставлены с EN,
прежним RU и составом кандидата. Дополнительные отрицательные случаи —
устаревший EN-пин, неверный прежний RU и непроверенное русское значение.

Контейнер: readonly input, непривилегированный пользователь, без сети и Docker
socket, 1 CPU/256 МиБ. Exit 0, OOM=false; собственные контейнеры и том удалены.
В Windows также пройдены 76 unit tests и Ruff по связанному helper/tests.
Две композиции совпали по файлам и ZIP. Повторно сверены 225 исходных JAR.

В отдельном временном дереве проверен возврат предыдущего языкового слоя:
личные options, JourneyMap и посторонние файлы сохраняются, неожиданно изменённый
управляемый файл блокирует процедуру до записи. Это проверка ресурса, не полный
откат мира или действующего сервера. [Протокол](validation/dj2-book-text-review-2026-11-14.json).
