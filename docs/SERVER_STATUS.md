# Онлайн на карточке сервера

API опрашивает Minecraft Java server-list status на адресах владельца.
`GET /servers/status` возвращает состояние, число игроков, лимит и время
проверки. В ответе нет ников, UUID, MOTD или внутреннего адреса.

Настройки передаются при запуске API. [Пример env](../deploy/api/server-status.example.env)

| Переменная | Назначение |
| --- | --- |
| `SERVER_STATUS_TARGETS` | JSON с ID сервера, `host` и `port`. До 8 целей |
| `SERVER_STATUS_CACHE_SECONDS` | Кеш worker API, по умолчанию 15 секунд (1–300) |
| `SERVER_STATUS_TIMEOUT_SECONDS` | Время опроса, по умолчанию 2 секунды (0,1–5) |

В Compose используйте имя Minecraft-контейнера, доступное API в общей сети,
или адрес входного шлюза. Допустимое значение цели — hostname или IP и
числовой порт.

Лаунчер обновляет онлайн раз в 30 секунд, пока открыта страница сборок.

| Надпись | Что означает |
| --- | --- |
| `Онлайн: 0 / 20` | Сервер ответил и указал ноль игроков и 20 мест |
| `Сервер недоступен` | API не получил корректный ответ Minecraft |
| `Онлайн недоступен` | Лаунчер не получил данные о статусе от API |
| `Сервер готовится` | Для этого профиля в API отсутствует цель опроса |

Во время обслуживания игрок при подключении видит причину, которую сообщает
[входной шлюз](OWNER_INGRESS.md). Показания TUI идут из
[системы мониторинга](OWNER_TUI.md), поэтому подтверждают другое состояние и
могут обновиться раньше счётчика в лаунчере.
