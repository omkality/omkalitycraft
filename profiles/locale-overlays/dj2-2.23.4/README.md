# Собственные дополнения перевода DJ2 2.23.4

`owned-ru.json` — исходные адресные дополнения: 191 языковая запись и 38 исправлений
подсказок. Первая порция — 95 записей, вторая — 96. Это данные для подготовки выпуска,
не готовый ресурспак и не настройка
лаунчера. Здесь нет полного заимствованного перевода или mod JAR.

Для каждой записи закреплён SHA256 **значения** актуального английского текста
в UTF-8, без `key=` и окончания строки. ID и placeholders могут остаться прежними
при изменении рецепта; hash требует повторно проверить смысл. Пин версии/commit
проверяется при сборке слоя. Новую DJ2 нельзя объявить совместимой только по этим
хешам: код, рецепты, ресурсы и игра проверяются отдельно.

Языковые дополнения передаются существующему `render_lang` вместе с
`expected_source_sha256`: все добавленные/изменённые записи должны иметь свои
пины, лишние/пропущенные/неверные отклоняются. Прежние вызовы без пинов совместимы.
Удаление старого alias — отдельное явное действие на проверенной исходной локали.
Сама функция работает с bytes, не устанавливает файлы и не вызывает сеть.

Схема 2, revision 2 связывается с предыдущей схемой 1 через SHA256 её JSON в UTF-8
с LF. Прежние 95 записей и `tips` сохранены. `base_state` различает отсутствие
ключа, английский текст внутри RU и явно проверенную правку русского текста.
У всех 45 изменяемых существующих значений второй порции есть дополнительный
`expected_previous_sha256`: SHA256 точного предыдущего RU-значения. Его нужно
проверить **до** замены; несовпадение означает новое ревью, а не принудительную запись.

Значение задаётся либо `ru`, либо списком `edits`. Последний нужен для шести
локальных исправлений без копирования полного стороннего текста в репозиторий:
`replace` заменяет единственное вхождение `old` на `new`; `truncate_before`
сохраняет префикс до единственного `marker`. `edit_reviewed_value` требует RU-пин,
1–8 буквальных операций, ограничивает UTF-8 bytes и отвергает неоднозначность,
физические новые строки, NUL и пустой результат. Regex/eval/файлового ввода нет.
Полученное значение затем обязательно проверяется `render_lang` с EN-пином и
placeholders. Помощник правки сам не знает актуального EN-контракта.

`meaning-review.json` фиксирует решения по 97 кандидатам «EN изменился, RU прежний»:
30 правок и 67 сохранённых переводов, с хешами старого/нового EN и прежнего RU.
Это не список 97 доказанных ошибок. Метаданные не содержат полных сторонних текстов.

В `tips` индекс используется вместе с hash исходного EN-текста. Тип
`project_adaptation` отличает правила проекта от обычной локализации: не обещаем
добавление модов в пользовательскую сборку и не ссылаемся на отсутствующую кнопку
старого главного меню. Полный список подсказок собирается из проверенного готового
перевода; позиции после лишней старой строки сопоставляются явно.

Полный assembled layer, заимствованные локали и source snapshots остаются вне Git.
Происхождение и условия их распространения проверяются до player payload.
Новых CLI, GUI, live installer или автоматического переключения manifest нет.
`game_tested=false` и `ready_for_players=false` сохраняются до приёмки клиента.
