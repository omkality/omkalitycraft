# Начальные клиентские настройки DJ2

`dj2.json` — фрагмент `launch.client_defaults` подписанного выпуска DJ2. Объединить
его с launch-profile перед `omk release pack`. В `servers` укажите рабочий
адрес совместимого сервера. Профиль установки подписывается вместе с manifest.
Лаунчер добавляет запись `Divine Journey 2 RU` при запуске игры, если её удалили.
Личные записи серверов сохраняются.

JourneyMap 1.12.2 5.7.1p3 использует каталог 5.7. Основная миникарта квадратная,
справа сверху, без сетки; полная карта тоже без сетки. JSON взяты из архивного
клиента владельца без карт, точек, миров или аккаунтов. Файлы создаются только
при отсутствии: личные изменения сохраняются при следующих запусках/обновлениях.
Вторая миникарта сохраняет настройки JourneyMap по умолчанию. Для новых установок
используется тема Stronghold. Маяки показывают небольшие иконки, название и расстояние
в фокусе. Оба луча и жирный шрифт выключены. Метки смерти создаются автоматически
и сохраняются до ручного удаления. Карты и данные меток остаются у игрока.

`initial_keybindings` добавляет только отсутствующие начальные привязки.
Квесты — K (LWJGL 37), очки Galacticraft — F12 (88). У Galacticraft ID привязки
локализован, поэтому профиль содержит русское и английское имена. Существующая привязка
со значением 0 тоже считается осознанным выбором и не заменяется. Уже существующий
конфликт K/K надо один раз устранить в Controls; этот код не сбрасывает старые настройки.

`.omk-initial-keybindings.json` отмечает применённые defaults: Minecraft удаляет
неиспользуемый языковой alias, и его нельзя добавлять заново при каждом запуске.
При полном удалении options.txt начальные настройки создаются снова. Проверяемый
профиль — русский DJ2; перенос пользовательских Galacticraft keys при смене языка
не объявляется решённым (это локализованные ID самого мода).

`initial_options` задаёт яркость 100%, обычный интерфейс, отключённые
покачивание/автопрыжок и поле зрения 80°. Для последнего Minecraft 1.12.2
хранит `fov:0.25` = `(80 − 70) / 40`; писать туда `80` нельзя. Отсутствующие
значения добавляются, существующие личные настройки сохраняются.

На Mac лаунчер 0.3.6 применяет облегчённые настройки DJ2 к отсутствующим
значениям в `options.txt`. Дальность составляет 6 чанков, число частиц
уменьшено, сложная графика, облака, сглаженное освещение и тени сущностей
выключены. Параметры частоты кадров задаются обычным профилем игры.

Начальные клавиши инвентаря и чата на Mac — E и T. Для сокращений модов
используется Command. Беспроводные терминалы открываются по Command+G/E/R/L
для обычного, крафтового, шаблонов и жидкостей соответственно.
В меню «Управление» можно выбрать другие клавиши.

Начальные параметры игры требуют лаунчер 0.3.0.dev13. Тема Stronghold и настройки
меток требуют минимум 0.3.0.dev17. Сначала опубликуйте совместимый лаунчер, затем
подписывайте следующий pack с этим минимумом. Настройки существующих установок
JourneyMap сохраняются.
