# Дополнения OmkalityCraft к DJ2 2.23.4

Это исходные файлы дополнения для следующего кандидата сборки. Профиль пока
не включён в игровой manifest и не выпущен пользователям. Он отделён от
ресурсного слоя локализации: скрипты меняют игровые данные и требуют своей
проверки, даже если большинство изменений выпуска — перевод.

`scripts/Unique/AtumKilnRegistryPolicy.zs` устанавливается по тому же пути
**одновременно на клиент и выделенный сервер**, до холодного запуска.
Он использует уже установленный CraftTweaker API Atum; новый мод не нужен.
Точные версии и хеши — в `profile.json`.

Проверены новый мир, настоящий графический клиент, повторное подключение
и обычная плавка редстоуновой руды. Строгие проверки модов и реестров сохранены.
Переход существующего мира без этой политики пока **не принят**: сохранённый
лишний ID вызывает отказ Forge. Нельзя автоматически отвечать на него
`/fml confirm` или удалять записи мира.

[Причина, границы проверки и возврат версии](../../../docs/DJ2_ATUM_KILN_POLICY.md).
