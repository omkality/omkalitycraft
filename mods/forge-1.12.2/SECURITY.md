# Сообщение об уязвимости

В публичном issue достаточно общего описания влияния без рабочего способа
обхода, игровых пакетов, токенов или данных игроков. Подробности передавайте
владельцу приватно через GitHub Security → Report a vulnerability либо Telegram,
указанный в лаунчере. Не проверяйте гипотезы на рабочем сервере или чужих базах.

Воспроизведение, исправление и проверка выполняются на изолированном стенде.
Детальный регрессионный тест публикуется после исправления и оценки раскрытия.
Публичность исходников не заменяет серверную авторизацию и проверку прав.
