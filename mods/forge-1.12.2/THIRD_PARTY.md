# Сторонние входы

Внешние JAR загружаются отдельно для компиляции. Они не хранятся в Git и не
включаются внутрь наших JAR. Точные источники, версии и SHA256 — в
[`build-tools.json`](build-tools.json): Eclipse ECJ, Minecraft Forge, FTBLib,
MixinBooter и Log4j API. Права и лицензии этих проектов сохраняются за авторами.

Log4j API 2.15.0 соответствует compile-time API в manifest закреплённого Forge;
Log4j Core не загружается этой сборкой. Это не установка или понижение версии
логирования работающего Minecraft-сервера.

`abi/` содержит собственные минимальные объявления нужных Java-типов для
компиляции против Forge. Реализации Minecraft не копировались и в результат
не включаются. Итоговые архивы проверяются на отсутствие `net/minecraft/` и
других сторонних классов.

Брендовая картинка загрузки предоставлена владельцем проекта и использует образ
игровой руды. Публикация этой композиции не означает передачи исключительных
прав на исходные игровые изображения или названия сторонних проектов.
