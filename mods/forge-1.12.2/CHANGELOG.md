# Изменения Forge-модов

## Client 0.1.3 — 14 ноября 2026

- Короткие русские подписи затрат Bewitchment без замены числовой логики
  исходного обработчика. В Roots переводится только заглушка отсутствующего
  основного множителя; значение не подменяется нулём, дополнительные расходы
  и конфликты сохраняются.
- 119 JVM-условий, 13 ресурсных тестов и две сборки из Git с точным SHA256.
  Нативное сравнение всех 37 ритуалов и 193 карточек выполняется внутри
  одного JVM на тех же объектах. 14 прежних классов не изменились;
  Core 0.3.8 и DJ2Fix 0.1.4 прежние.
  [Контракт и приёмка](../../docs/CLIENT_RUNTIME_BOOK_LABELS.md).
- Это исходный этап; пользовательский профиль и VPS не переключены.

## Client 0.1.2 — 14 ноября 2026

- Необязательные русские подписи обложки/оглавления Extra Utilities 2 и номера
  издания Patchouli. Поздний загрузчик обычных модов, отдельный JVM-флаг,
  явный формат ресурсов 3; ранний сетевой/косметический загрузчик прежний.
- Исправлен обнаруженный в частном прототипе порядок загрузки, приводивший
  к падению Patchouli. Проверки обработчиков дополнены настоящим холодным
  клиентом DJ2 и Linux Docker-сервером; прототип в профиль игроков не попадал.
- 95 JVM-условий и две воспроизводимые сборки; Core 0.3.8 и DJ2Fix 0.1.4 прежние.
  [Контракт и границы](../../docs/CLIENT_BOOK_LOCALE.md).
  Пользовательский manifest, Release и VPS не переключены.

## Core 0.3.8 — 13 ноября 2026

- Generic opt-in `/guide` и отложенная памятка в чате для первых игровых часов.
  Текст вне Java; существующие vanilla stats, cooldown в Forge PlayerPersisted,
  bounded login queue, validated env. Без FTB-зависимости и нового счётчика/БД.
- Проверены policy/queue, non-OP chat packets DJ2/Linux Docker, отмена ожидания,
  restart и сохранность player state; отдельный minimal Forge без FTB/DJ2.
  Графическое отображение пока не принято. [Контракт](../../docs/NEW_PLAYER_GUIDE.md).
- Metrics сообщает общую VERSION-константу. Два чистых build воспроизводимы;
  DJ2Fix 0.1.4 и Client 0.1.1 прежние. Player manifest/VPS не переключаются.

## Core 0.3.7 — 13 ноября 2026

- Общий opt-in producer Forge 1.12.2: фактические TPS по скользящему окну,
  MSPT mean/p95/max из штатных колец, loaded dimensions, online и heap/GC MXBeans.
  Нет новых player/CLI команд, зависимости от FTB/DJ2 и удалённого JMX/RCON.
- Ограниченный async writer, private atomic JSON, один owner, очередь на один
  ожидающий снимок. I/O failure не прекращает игровые тики; stale различает reader.
- Настоящая DJ2 2.23.4 с двумя Drasl actors, pause/stale/recovery, два старта/rejoin,
  сохранность вещей/XP; отдельно минимальный Forge без DJ2/FTB с отказом записи.
  27 pure Java controls и воспроизводимые builds. [Контракт](../../docs/GAME_RESOURCE_HISTORY.md).
- DJ2Fix 0.1.4 и Client 0.1.1 побайтно прежние. Рабочие manifests/VPS и player
  release автоматически не переключаются. Это не полная игровая регрессия сборки.

## Core 0.3.6 — 12 ноября 2026

- Внутренний RCON-only main-thread bridge для loaded backup policy и фиксированных
  предупреждений ночного обслуживания. Это общий Core 1.12.2 с optional FTB
  provider; pack-specific логика в Core не добавлена.
- Boot fence, повтор без рассылки, отказ при partial/overflow/неподдержанном
  состоянии. Новых player/CLI действий нет; scheduler не включён.
- DJ2/Linux Docker с двумя Drasl-игроками, lost-ACK/старый boot/OP sender, clean
  stop без crash/OOM. Испытания и границы: [протокол](../../docs/validation/maintenance-bridge-2026-11-12.json).
- 12 Java helper controls и два воспроизводимых Linux build. DJ2Fix 0.1.4 и
  Client 0.1.1 побайтно прежние; рабочие manifests автоматически не переключаются.

## DJ2Fix 0.1.4 — 10 ноября 2026

- Условия использования переносимого телепортера Mekanism повторно проверяются
  на серверном потоке до изменения игрока, предмета и адресата. При отказе нет
  частичного списания; штатные рецепты, стоимость, обе руки и публичные сети
  сохраняются.
- Native-артефакт закреплён по SHA256, точка Mixin обязательна; профиль требует
  версию 0.1.4 и возможность `fix.mekanism.portable`.
- Core 0.3.5 и Client 0.1.1 не изменены. Клиентские manifests и рабочие миры
  автоматически не переключаются. [Приёмка и ограничения](../../docs/DJ2_MEKANISM_PORTABLE.md).

## Публичный исходный снимок — 10 ноября 2026

- Core 0.3.5: общий серверный API расширений, требования профиля и интеграции FTB.
- DJ2Fix 0.1.3: отдельная композиция проверенных исправлений DJ2.
- Client 0.1.1: изоляция отложенных сетевых задач по подключению и опциональное
  оформление загрузки Forge.
- Чистый импорт без прежней приватной Git-истории и лаборатории. Исходные
  реализации не изменены; версии JAR сохранены.
- Сборка из закреплённых входов, два повтора в Linux Docker и проверка полного
  совпадения с принятыми JAR. Исправлена зависимость метаданных/порядка ZIP от ОС.
- Приватная полная история сохранена отдельно. Открытые серверные проблемы и
  полная приёмка DJ2 остаются в issue tracker; этот снимок их не закрывает.
