# Изменения Forge-модов

## Core 0.3.6 — 12 ноября 2026

- Внутренний RCON-only main-thread bridge для loaded backup policy и фиксированных
  предупреждений ночного обслуживания. Это общий Core 1.12.2 с optional FTB
  provider; pack-specific логика в Core не добавлена.
- Boot fence, повтор без рассылки, отказ при partial/overflow/неподдержанном
  состоянии. Новых player/CLI действий нет; scheduler не включён.
- DJ2/Linux Docker с двумя Drasl-игроками, lost-ACK/старый boot/OP sender, clean
  stop без crash/OOM. Испытания и границы: [протокол](../../docs/validation/maintenance-bridge-2026-11-12.json).
- 12 Java helper controls и два воспроизводимых Linux build. DJ2Fix 0.1.4 и
  Client 0.1.1 побайтно прежние; рабочие manifests автоматически не переключаются.

## DJ2Fix 0.1.4 — 10 ноября 2026

- Условия использования переносимого телепортера Mekanism повторно проверяются
  на серверном потоке до изменения игрока, предмета и адресата. При отказе нет
  частичного списания; штатные рецепты, стоимость, обе руки и публичные сети
  сохраняются.
- Native-артефакт закреплён по SHA256, точка Mixin обязательна; профиль требует
  версию 0.1.4 и возможность `fix.mekanism.portable`.
- Core 0.3.5 и Client 0.1.1 не изменены. Клиентские manifests и рабочие миры
  автоматически не переключаются. [Приёмка и ограничения](../../docs/DJ2_MEKANISM_PORTABLE.md).

## Публичный исходный снимок — 10 ноября 2026

- Core 0.3.5: общий серверный API расширений, требования профиля и интеграции FTB.
- DJ2Fix 0.1.3: отдельная композиция проверенных исправлений DJ2.
- Client 0.1.1: изоляция отложенных сетевых задач по подключению и опциональное
  оформление загрузки Forge.
- Чистый импорт без прежней приватной Git-истории и лаборатории. Исходные
  реализации не изменены; версии JAR сохранены.
- Сборка из закреплённых входов, два повтора в Linux Docker и проверка полного
  совпадения с принятыми JAR. Исправлена зависимость метаданных/порядка ZIP от ОС.
- Приватная полная история сохранена отдельно. Открытые серверные проблемы и
  полная приёмка DJ2 остаются в issue tracker; этот снимок их не закрывает.
