# OmkalityClient 0.1.3

Отдельный клиентский адаптер для Forge 1.12.2. Сетевое задание запоминает
исходный NetworkManager: после закрытия подключения не выполняется только
принадлежащее ему отложенное задание. Контекст снимается в `finally`; задания
нового подключения и обычные несетевые задания сохраняются. Исключения живых
подключений не скрываются, общая очередь Minecraft не очищается.

Косметические Mixin для логотипа и tint Forge включаются только с
`-Domkality.appearance.forge112=true`. Цвета и прогресс задаются стандартным
`splash.properties`; этот компонент не меняет рецепты или игровой баланс.

Необязательные подписи книг включаются отдельно:
`-Domkality.books.locale.forge112=true`. Классы обычных модов обрабатываются
через `ILateMixinLoader`; ранний загрузчик сети/оформления не изменён.
Для русского языка переводятся обложка и оглавление Extra Utilities 2,
убирается английский порядковый суффикс номера издания Patchouli. Другие языки
сохраняют исходное поведение; ветки нулевого и разрабатываемого издания прежние.
Номера страниц, ссылки, автор, содержимое книги и игровой прогресс не меняются.

Версия 0.1.3 дополнительно переводит короткие подписи «Запуск»/«Расход»
в ритуалах Bewitchment. Числа продолжает вычислять исходный обработчик.
В карточках Roots отсутствие основного множителя обозначается «Не задано»:
это не нулевая стоимость и не отмена дополнительных затрат.
[Контракт и проверка динамических данных](../../../docs/CLIENT_RUNTIME_BOOK_LABELS.md).

Это клиентская необязательная интеграция, по умолчанию выключенная.
Пакет явно объявляет `pack_format=3`, чтобы Forge читал `en_us.lang`/`ru_ru.lang`
без устаревшего адаптера. Отсутствие требуемой точки изменения при включённой
интеграции не маскируется. [Приёмка и возврат](../../../docs/CLIENT_BOOK_LOCALE.md).

`src/` и собственные `resources/` входят в JAR. Минимальные объявления из `abi/`
используются только для компиляции; классы Minecraft и `test/` в JAR не входят.
Сборка выполняет 119 JVM-проверок: сеть 14, локализация 30, обработчики 50,
границы позднего загрузчика 9, подписи ритуалов 16. Проверяются четыре ресурсных
контракта и два косметических target закреплённого Forge. Эти проверки не
заменяют запуск игры.
Порядок сборки и версии — в [общем README](../README.md).

Этот компонент не удостоверяет подлинность чужого клиента. Авторизация,
инвентари, приваты и допустимость действий проверяются сервером. Совместимость
другой версии Minecraft/Forge требует самостоятельной приёмки.
