# Моды OmkalityCraft

Исходники наших Forge-модов входят в этот монорепозиторий. Текущая платформа —
[Forge 1.12.2](forge-1.12.2/README.md); другие версии требуют отдельных адаптеров
и приёмки. Python отвечает за лаунчер/API/операции, Java — за интеграцию с игрой.

| Компонент | Версия исходников | Сторона |
| --- | --- | --- |
| OmkalityCore | 0.3.5 | Сервер |
| OmkalityDJ2Fix | 0.1.3 | Сервер DJ2 |
| OmkalityClient | 0.1.1 | Клиент |

Версии компонентов независимы от версии лаунчера. Публичная история начинается
с проверенного импорта 10 ноября 2026; полная прежняя Git-история сохранена в
локальном приватном архиве. Лаборатория с подробными воспроизведениями открытых
проблем остаётся приватной и не входит в этот каталог.

Публикация исходников не означает готовность серверного профиля для игроков.
Состояние первого запуска DJ2 — в [#41](https://github.com/omkality/omkalitycraft/issues/41).
GitHub Releases этого монорепозитория по-прежнему предназначены для лаунчера.
