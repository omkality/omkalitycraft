# Моды OmkalityCraft

Исходники наших Forge-модов входят в этот монорепозиторий. Текущая платформа —
[Forge 1.12.2](forge-1.12.2/README.md); другие версии требуют отдельных адаптеров
и приёмки. Python отвечает за лаунчер/API/операции, Java — за интеграцию с игрой.

| Компонент | Сторона |
| --- | --- |
| OmkalityCore | Сервер |
| OmkalityDJ2Fix | Сервер DJ2 |
| OmkalityClient | Клиент |

Версии и хеши компонентов закреплены в [versions.json](forge-1.12.2/versions.json).
Публичная история начинается с проверенного импорта 10 ноября 2026.
Прежняя Git-история сохранена в локальном архиве. Лаборатория с подробными воспроизведениями открытых
проблем остаётся приватной и не входит в этот каталог.

Приёмка первого выпуска DJ2 описана в [#38](https://github.com/omkality/omkalitycraft/issues/38).
GitHub Releases этого монорепозитория по-прежнему предназначены для лаунчера.
